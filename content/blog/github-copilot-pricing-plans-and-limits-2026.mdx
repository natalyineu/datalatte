GitHub Copilot has a free plan, then Pro at $10 a month, Pro+ at $39 and Max at $100, all per user. Inline code suggestions are unlimited on the paid plans, while chat and agent work draw on a monthly allowance of AI credits worth one US cent each. Older guides talk about "premium requests"; the GitHub pages opened for this guide use AI credits instead.

This guide is for owners and marketers of local businesses who wonder whether a coding assistant is worth paying for. It covers what each plan costs, what the credits are, what happens when they run out, and where the tool fits. Every number comes from GitHub's own pages, listed in Sources.

## How Much Does GitHub Copilot Cost?

GitHub's plans page lists four individual plans, all with monthly prices only. No annual price appeared on the page.

| Plan | Price | Monthly AI credits (GitHub Docs) | What the plans page adds |
|---|---|---|---|
| Free | $0 | An allowance, amount not stated | 2,000 completions a month, entry-level models, agent mode and Copilot CLI included |
| Pro | $10 per user a month | 1,000 base + 500 flex = 1,500 | Unlimited inline suggestions, Copilot in the cloud, code review, model selection |
| Pro+ | $39 per user a month | 3,900 base + 3,100 flex = 7,000 | Everything in Pro, premium models including Opus, audit logs, "4x+ included usage than Pro" |
| Max | $100 per user a month | 10,000 base + 10,000 flex = 20,000 | Everything in Pro+, priority access to new models, "2.9x+ included usage than Pro+" |

A Student plan is free for verified students, with an allowance of credits and auto model selection only. Verified teachers and maintainers of popular open-source projects may also qualify for free Pro access. Business and Enterprise plans exist for organizations and are not covered here.

## What Are AI Credits and What Happens When They Run Out?

GitHub Docs says the cost of a request depends on the model and the number of tokens used. Longer conversations, agentic features and more capable models use more credits. Base credits are used first, then the flex allotment. Unused credits are forfeited: the allowance resets at 00:00 UTC on the first day of each calendar month, whatever the billing date.

Credits apply to Copilot Chat, Copilot CLI, the cloud agent, Spaces, Spark and third-party coding agents. Completions and next edit suggestions are not billed in credits.

When an individual's allowance is used up, there are three routes:

- **Upgrade.** Pay only the price difference to the next tier. Usage earlier in the cycle counts toward the new allowance.
- **Set an extra-usage budget.** Pay by the dollar for more credits. The page notes this may be capped.
- **Wait.** The allowance returns next month.

Extra usage "is billed after it occurs". Usage from the last days before cancelling must still be paid. The same page says paid plans get 10% off model costs when using auto model selection in Copilot Chat or the cloud agent.

## What Is GitHub Copilot and How Does It Work?

GitHub Docs describes Copilot as "an AI assistant that helps you write, understand, and ship software." It has an assistive side, which suggests code and answers questions while you work, and an agentic side, where you describe a goal and Copilot works through several steps. The docs also describe an agent that can research a repository, make changes and prepare a pull request for your review.

That last point matters for non-developers. Copilot lives where code lives: inside a code editor or on GitHub. The pages opened did not describe a chat-to-website builder, so a person with no GitHub account or editor will find it less direct than the app builders in this batch, such as [Lovable](/blog/lovable-pricing-and-credits-2026) or [Bolt.new](/blog/bolt-new-pricing-and-tokens-2026).

## Which Models Does Copilot Offer?

The plans page lists the same 35 models on every plan, including Free, from Anthropic, OpenAI, Google, xAI, Microsoft and others. Examples shown include Claude Sonnet 5.5, Claude Opus 5.5, GPT-6.1 Sol, Gemini 4 Argon and Grok 4.7. The Free plan note says access is to entry-level models, and the Docs add that Free and Student use auto model selection only.

Model names move quickly, and a name on a list does not mean every plan can use it without limit. Credits are spent faster on bigger models. Check the live list when signing up.

## What Are the Risks and Limits?

- **Allowance, not unlimited.** Chat and agent work is metered in credits, and the Free allowance amount is not stated.
- **Extra usage bills later.** Spending above the allowance is billed after it occurs, so set a budget.
- **Features by plan.** The plans page lists cloud agent, code review and assigning work to Copilot as not included on Free.
- **Not on individual plans.** Enterprise security, IP indemnity, SAML single sign-on, usage metrics and user management on github.com are listed as not included on individual plans.
- **Review.** GitHub's own wording is that Copilot prepares changes "for your review". Treat them as drafts.

This guide did not open GitHub's data and privacy terms for individual plans, so what is stored or used for training is not stated here. Read them before pasting customer data into chat.

## FAQ

### Is GitHub Copilot free?

Yes, there is a Free plan at $0. GitHub's page says it is limited to 2,000 completions and entry-level models per month, and it includes agent mode and Copilot CLI. It has an allowance of AI credits whose size is not stated. Verified students can use the free Student plan.

### How much does GitHub Copilot cost per month?

Pro is $10 per user, Pro+ is $39 and Max is $100. The plans page shows monthly prices only. Business and Enterprise plans are separate and priced per organization.

### What are premium requests in Copilot?

Older guides use that term. The GitHub pages opened on 7 November 2026 describe AI credits instead, where one credit equals $0.01, and do not mention premium requests. Pro includes 1,500 credits a month, Pro+ 7,000 and Max 20,000.

### What happens when Copilot credits run out?

You can upgrade and pay the price difference, set a dollar budget for additional usage, or wait until the allowance resets on the first of the month at 00:00 UTC. Unused credits do not carry over.

### Is GitHub Copilot worth it for a small business?

It depends on who edits the site. It suits an owner or freelancer who already works in a code editor. Without that, a chat-based builder may be simpler. The Free plan costs nothing, so test there first.

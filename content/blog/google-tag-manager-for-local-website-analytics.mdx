Google Tag Manager (GTM) is a free tool that lets you add and change tracking tags on a website without editing the site's code each time. For a local business, the usual job is to send Google Analytics 4 (GA4) the actions that matter, such as phone taps, booking clicks and form sends. You install two snippets once, then manage everything in the GTM interface.

This guide explains what GTM does, what GA4 already tracks for you, how to set up a call-tap tag, and how to test it. Facts are sourced at the end.

## What Does Google Tag Manager Do for a Local Business?

Google defines Tag Manager as a tag management system that lets you manage tags on a website or app without changing its code after the install. A container holds your tags, triggers and variables. A tag is a snippet that sends data or runs a function, a trigger says when the tag fires, and a variable is a reusable value.

Google says standard Tag Manager is free. That removes the main objection for a small business, though the time to set it up and test it is still a cost.

## What Does GA4 Already Track Without GTM?

More than most owners expect. GA4's enhanced measurement collects page views and, unless you switch them off, scrolls at 90% depth, outbound link clicks, site search, form interactions (form_start and form_submit), file downloads and embedded YouTube video engagement. Only page views cannot be turned off.

So check GA4 before you build tags. Duplicating a form event you already receive gives inflated numbers. What GA4 does not know by default is that a tap on a phone number or a Book Now link on another domain matters to you. That is the gap GTM fills.

## How Do You Install GTM?

1. Create a Tag Manager account and a web container for your domain.
2. Add the two container snippets Google provides to every page, following the placement instructions shown in your container. On website builders, look for a header and body code field or a built-in GTM option.
3. Add a Google Analytics configuration tag so GA4 data flows through the container. Google notes the Google tag should appear only once per page, so remove any old GA4 snippet to avoid double counting.
4. Publish the container.

Our [small business GTM guide](/blog/google-tag-manager-for-small-business) covers the account setup in more detail, and the [GA4 settings guide](/blog/google-analytics-4-for-small-business) lists what to configure first.

## How Do You Track Phone Taps and Booking Clicks?

Create a trigger that listens for clicks on links, then add a condition on the link address, for example one that begins with tel: for phone numbers or contains your booking tool's domain. Connect that trigger to a GA4 event tag with a clear name like phone_tap or booking_click.

Google's trigger documentation describes triggers as listening for events like form submissions, button clicks or page views. It does not give a tel: recipe, so build and test the condition on your own site, because the click variables available depend on how your site's links are built. Then, in GA4, mark the events that represent real business as key events. Google says any collected event can become one, and it can be shared with Google Ads as a conversion.

## How Do You Test Before Publishing?

Use Preview mode. Google describes it as browsing your site as if the current container draft were live, with Tag Assistant showing which tags fired and when. Click each phone link and booking button, and check that the matching tag fires once, not twice.

Make sure your Business Profile phone and booking link match the site too; see our [Business Profile checklist](/blog/google-business-profile-optimization-checklist). Then open GA4 and look for the event in the real-time or debug view. Publish only when every tag behaves. Name each version so you can find it later.

## FAQ

### Is Google Tag Manager free?

Yes. Google describes the standard version as free. Tag Manager 360 is a separate version aimed at larger organizations; Google's page does not list its price.

### Do I need GTM if I already have GA4?

Not always. GA4 collects page views, scrolls, outbound clicks, form interactions and downloads by default. GTM helps when you need custom events, such as phone taps, or want to manage several tags without developer help.

### Can GTM slow down my website?

Every tag adds some load. Keep the container to the tags you need and remove old ones. Google does not publish a standard speed cost.

### How do I know my tags work?

Use Preview mode and Tag Assistant, then confirm the events in GA4 before you publish. Our [GA4 guide](/blog/google-analytics-4-for-small-business) shows what to check next.

### Should I mark every event as a key event?

No. Google says a key event tracks an action that matters most to your business. Pick bookings, calls and form sends, not scrolls.

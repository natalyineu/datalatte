n8n is a workflow automation tool that connects apps such as Gmail, Google Sheets and Google Calendar with a visual editor. A local business can start with n8n Cloud, which its pricing page lists at €20 a month billed annually for 2,500 workflow executions, or self-host the free Community edition. n8n publishes no figure for hours saved, so this guide gives no such promise.

The five automations below use nodes documented by n8n. Examples marked as assumptions are illustrations, not results from any business.

## What Does n8n Cost for a Small Business?

The n8n pricing page lists Starter at €20 a month billed annually with 2,500 executions, Pro at €50 with 10,000, and Business at €667 with 40,000 on self-hosted only. Enterprise is custom. A monthly billing toggle exists, but the monthly prices did not appear when we read the page.

An execution is a single run of your entire workflow, however many steps it has. A workflow that runs once a day uses about 30 executions a month. A self-hosted Community edition is available on GitHub with no listed price.

## Is n8n Free to Self-Host?

The software is free to run, but you carry the server, updates and backups. n8n's hosting docs describe Docker Compose for production and a one-line setup script, and say npm installation is deprecated from n8n 3.0. Without a license key, a self-hosted instance runs as the free Community edition.

The Sustainable Use License allows use for your own internal business purposes or non-commercial use. Sharing it is allowed only free of charge and non-commercially. If you plan to resell n8n as a service, read the license text on GitHub first.

## Which Automations Are Worth Building First?

Pick tasks that are repetitive, rule-based and low risk. All five use n8n nodes whose operations are documented:

- **Daily booking digest:** the Schedule Trigger runs at a fixed time, reads rows from Google Sheets and emails the day's list through Gmail.
- **Lead capture:** a Webhook node receives a form submission and appends a row in Google Sheets.
- **Appointment check:** Google Calendar's Get Many events and Availability operations read your calendar.
- **Email draft for enquiries:** Gmail can create a draft for you to review before sending.
- **Review request list:** a sheet of recent customers feeds a reminder for staff to ask for reviews.

## What Do the Key Nodes Actually Do?

The Schedule Trigger runs at intervals from seconds to months or on a cron expression. The workflow must be published for it to run, and it uses the workflow or instance timezone: self-hosted defaults to America/New York and Cloud to GMT. Set the timezone first.

The Webhook node creates a URL that receives data and supports GET, POST and other methods, with a 16 MB payload limit. It has separate test and production URLs. Gmail supports sending, replying and creating drafts, and Google Sheets supports append, update and get rows.

## The Math: Will Your Plan Cover Your Workflows?

All inputs are **assumptions**. A salon builds a daily digest, a form capture workflow and a review-request list.

| Workflow | Assumed runs per month | Executions |
| --- | --- | --- |
| Daily booking digest | 30 days | 30 |
| Form capture (one run per submission) | 80 submissions | 80 |
| Review-request check, daily | 30 days | 30 |
| Total | | 140 |

140 executions is far under Starter's 2,500. The limit matters if a workflow runs per customer message, because each run counts. If you send an automated reply to 100 messages a day, that is about 3,000 executions a month and exceeds Starter. Estimate runs before choosing a plan.

## FAQ

### Is n8n free?

A self-hosted Community edition is available on GitHub. n8n Cloud is paid, starting at €20 a month billed annually for 2,500 executions.

### Do I need to code to use n8n?

The editor is visual. n8n's hosting docs do not state a skill level, but self-hosting involves Docker or similar, so many small businesses choose Cloud.

### What counts as an execution?

n8n says an execution is a single run of your entire workflow. Step count and data volume do not change that.

### Can n8n send emails and read my calendar?

Yes. Documented operations include Gmail send, reply and draft, and Google Calendar get, create and availability.

### How many hours will n8n save me?

n8n publishes no figure. Time them yourself: count the minutes the task takes now, then compare after a month.

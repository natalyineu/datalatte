Qwen is a good model family to try through OpenRouter when your customers write in several languages, because one API key and one endpoint reach many Qwen versions at low prices. Alibaba's Qwen3.5 lists support for 201 languages and dialects, Qwen3 lists 119, and Qwen 2.5 lists more than 29.

Prices on OpenRouter start at $0.03 per million input tokens for Qwen3.7 Flash.

This guide covers review replies, booking messages and bilingual emails for local businesses. Figures were checked on 24 October 2026 from vendor pages and OpenRouter's live model list. There is no verified head-to-head language score here, because none could be found in an open source. A short test method is included instead.

## Why Does Language Matter for a Local Business?

Census data shows how many customers may write in another language. In the 2018 to 2022 US Census survey, 78.3% of people aged 5 and over spoke only English at home, and Spanish made up 61.1% of the rest.

The ONS says 91.1% of residents of England and Wales aged three and over had English (or Welsh in Wales) as their main language in 2021, with Polish at 1.1%, Romanian 0.8%, Panjabi 0.5% and Urdu 0.5%.

In Australia's 2021 Census the top non-English languages at home were Mandarin 2.7%, Arabic 1.4%, Vietnamese 1.3%, Cantonese 1.2% and Punjabi 0.9%. Local shares vary a lot by suburb, so check your own area's census profile before you add a language.

## How Do You Call Qwen From OpenRouter?

OpenRouter's base URL is https://openrouter.ai/api/v1 and its chat completions endpoint follows the OpenAI format. The OpenAI SDK works as a drop-in replacement: change the base URL and use your OpenRouter key as a bearer token. A request needs a model ID and a list of messages, each with a role and content.

In a no-code tool such as Make or n8n, use the HTTP module with the same fields. Put your instructions, tone and language rule in the system message, and the customer text in the user message. See our [Make.com workflow guide](/blog/make-com-ai-agent-workflow-local-business) for the surrounding steps.

## What Can You Automate With Multilingual Qwen?

Four tasks fit local businesses well. In each, keep a person in charge of anything sensitive.

- **Review replies.** Detect the review language and reply in the same language. Google's Business Profile API lets an application reply to a review, but it requires API access. Many owners paste drafts by hand. See our [review auto-reply script](/blog/ai-agent-google-reviews-auto-reply-script).
- **Bilingual emails.** Ask for a culturally adapted version in each language, not a literal translation, and have a native speaker approve the first batch.
- **Booking enquiries.** Classify the language and intent, then draft a reply from your real opening hours and prices.
- **FAQ drafts.** Generate answers in each language from a document you supply, so the model does not invent policies.

For messaging apps, read the [WhatsApp Business automation guide](/blog/whatsapp-business-api-local-marketing-automation) and, for a multilingual market, the [Singapore guide](/blog/local-marketing-singapore-small-business-guide).

## What Does WhatsApp Automation Cost Now?

Meta's documentation says it has used per-message pricing since 1 July 2025, with rates based on message category and the recipient's country calling code. A 24-hour customer service window opens when a customer messages you, and outside it only template messages are allowed. Service messages are free only up to 1,000 per business phone number per month.

Meta also states that from 1 October 2026 it charges again for utility messages sent inside an open service window. Check the current rate card before promising customers automated replies, because older conversation-based pricing no longer applies.

## What Does a Reply Cost? A Worked Example

All inputs are **assumptions**: each review reply uses 400 input tokens (instructions plus the review) and 150 output tokens. The estimate ignores any hidden reasoning tokens that some newer models produce.

| Model | Cost per reply | Cost for 1,000 replies |
| --- | --- | --- |
| qwen/qwen3.7-flash | about $0.00003 | about $0.03 |
| openai/gpt-4o-mini | about $0.00015 | about $0.15 |
| qwen/qwen-2.5-72b-instruct | about $0.0002 | about $0.20 |

Even the dearest option is cents per thousand replies. The real cost is review time. If a native speaker spends two minutes checking each of 50 replies a month (assumption), that is about 100 minutes, far more than the API bill.

## How Should You Test Language Quality?

Use a small blind test. Take 20 real messages per language, generate replies from two or three models with the same prompt, remove the model names, and have a fluent speaker rate each reply for correctness, tone and local wording. Count how many they would send unedited.

Check dialect and script too. Qwen can produce Simplified Chinese by default, so state Traditional Chinese in the prompt if you need it. For Arabic, say which dialect you want. These behaviours were not benchmarked in the sources above, so confirm them yourself.

## Is It Safe to Send Customer Data Through OpenRouter?

OpenRouter says each provider has its own data policy. You can block routing to providers that may train on your data in account settings, and filter by data policy per request. Its privacy page does not describe a dedicated zero-retention setting.

So send as little personal data as possible: a first name and the message text, not phone numbers, payment details or health information. If you need regional processing, OpenRouter offers in-region routing on eu.openrouter.ai for eligible models on Business and Enterprise plans, and the Qwen 2.5 72B model is not eligible.

## FAQ

### How many languages does Qwen support?

Alibaba lists more than 29 for Qwen 2.5, 119 languages and dialects for Qwen3, and 201 for Qwen3.5. Listed support is not the same as equal quality in each language.

### Is Qwen better than ChatGPT for Chinese?

No verified comparison was found, so this guide makes no claim. Test both on your own messages.

### How much does Qwen cost on OpenRouter?

Between $0.03 and $0.36 per million input tokens for the models in the table above, as of 24 October 2026. Check the live list before you budget.

### Can I run Qwen myself?

Many Qwen models are open-weight. The 7B and Qwen3 dense models are listed under Apache 2.0, while Qwen 2.5 72B uses the Qwen licence, so read the licence first.

### Should I use the newest Qwen model?

Not automatically. Newer models may add reasoning tokens that raise cost and delay. Test one small, cheap model first.

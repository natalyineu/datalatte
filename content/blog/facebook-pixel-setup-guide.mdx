Meta's developer documentation lists these steps. The whole job takes under an hour on a simple site.

This guide is for local businesses that run or plan to run Meta ads and have a website or booking page they can edit. Facebook Pixel is now called Meta Pixel; it is the same tool. Everything below comes from Meta's own documentation, listed at the end.

## What Does the Meta Pixel Actually Do?

The Pixel is a piece of JavaScript on your site. When a visitor loads a page or takes an action, it sends an event to Meta. Meta's documentation says the base code automatically calls `fbq('track', 'PageView')` on each page load. You then add events for actions such as a form submission or a booking.

Those events let you see which ads lead to actions, and they give Meta data to optimize delivery. Without them you only see clicks, not customers. If you are new to tracking tags in general, read [what a pixel tag is](/blog/what-is-a-pixel-tag-tracking-local-business) first.

## How Do You Set Up the Pixel in 5 Steps?

1. **Create the Pixel.** In Ads Manager, open Events Manager and create a Pixel or dataset for your website. Meta says the base code is found there.
2. **Install the base code.** Meta "highly recommends" placing it between the opening and closing head tags on every page you track. This lowers the chance that browsers or other code block it.
3. **Leave PageView in place.** Meta recommends keeping the automatic PageView call intact.
4. **Verify.** Load a page of your site. If a new PageView appears in Events Manager, the install worked. If not, wait a few minutes, refresh, then use Meta's debugging tools.
5. **Add one conversion event.** See the next section.

If you use a tag manager, Meta says the Pixel works with most of them, so check your tag manager's documentation. Meta describes an image-tag install as an option but does not recommend it. If your mobile site is separate, install the Pixel on both. For the order of tag installs, see [Facebook Pixel vs Google Tag](/blog/facebook-pixel-vs-google-tag-which-to-install-first).

## Which Event Should a Local Business Track First?

Pick the one action that most often turns a visitor into a customer. Meta lists 17 standard events, including Lead, Contact, Schedule, FindLocation, Purchase, Subscribe and CompleteRegistration. For a local service business the usual choices are:

| Business action | Standard event | Where it fires |
| --- | --- | --- |
| Contact form sent | Lead | Thank-you page or form submit |
| Booking made online | Schedule | Booking confirmation page |
| Click on "Get directions" | FindLocation | On the button click |
| Click on phone number | Contact | On the button click |
| Online order or deposit | Purchase | Order confirmation page |

Meta's documentation shows a Purchase call with `fbq('track')`, the event name, and a currency and value of 30.00 USD. For Purchase, currency and value are required. Standard events can sit anywhere between the opening and closing body tags, and can fire on page load or on an action such as a button click. The base code must already be on that page.

Custom events use `fbq('trackCustom')` with a name of up to 50 characters. Use them only when no standard event fits. Parameters go in a JSON-formatted object as the third argument.

## How Do You Test That the Pixel Works?

Meta recommends its Meta Ads Data Advisor Chrome extension to verify the Pixel, especially when tracking conversions. Open your site with the extension on, click through to the thank-you page, and check the event name appears once.

Then look in Events Manager. A new event there means Meta received it. Meta's support page also lists a known cause of broken links from ads: URL shorteners and vanity URLs can swap the `&` in the `fbclid` click ID for a `?`, which produces 404 errors. Use full URLs for ad destinations.

Meta's dedicated Test Events documentation page returned a 404 on 2026-11-01, so this guide does not describe that tool. Look for it inside Events Manager.

## Should You Also Add the Conversions API?

The Pixel runs in the visitor's browser. The Conversions API sends events from your server or systems to Meta. Meta says that if you already have a Pixel, you can set up the Conversions API for website events in one click from Events Manager, with no code or setup fees.

If you run both, Meta recommends passing an `eventID` as a fourth parameter to `fbq('track')` so browser and server events can be matched. Meta's overview page only states that deduplication should be confirmed when you verify setup; it does not explain the mechanics. For a one-location shop, the Pixel alone is a reasonable start. Add the API if you use a website platform with a built-in Meta integration or you see gaps in reported conversions.

## Worked Example: Is One Event Enough?

Every figure here is an **assumption**, not a benchmark. A salon spends $300 a month on Meta ads. The website has a booking button that leads to a confirmation page.

| Item | Assumption |
| --- | --- |
| Monthly ad spend | $300 |
| Event tracked | Schedule on the confirmation page |
| Events recorded in Events Manager | 12 |
| Cost per tracked booking | $300 / 12 = $25 |
| Average first visit value | $70 |

At these inputs, each tracked booking costs $25 against a $70 visit. If the Pixel were missing, the same $300 would only show clicks. Check real bookings against the count: if the salon's calendar shows 15 online bookings but the Pixel shows 12, some are not being tracked, which is a reason to look at the Conversions API or the event placement.

## FAQ

### Is the Facebook Pixel the same as the Meta Pixel?
Yes. Meta renamed its business products, and its documentation now says Meta Pixel. The function name in the code is still `fbq`.

### Where does the Pixel code go?
Meta recommends the head section of every page you track. Event code can go anywhere between the opening and closing body tags.

### How do I know the Pixel is working?
Load a page with the Pixel and check Events Manager for a PageView. Meta says to wait a few minutes and refresh if it does not show at once.

### Do I need the Conversions API?
Not to start. Meta offers a one-click setup for website events if you already have a Pixel, so you can add it later.

### Can I track phone calls?
You can fire a Contact event when someone clicks a phone link on your site. That records the click, not whether the call connected.

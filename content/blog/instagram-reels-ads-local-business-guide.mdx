## How Many Local Customers Use Instagram?

Pew Research Center's 2026 survey found that 51% of US adults use Instagram, compared with 70% for Facebook and 84% for YouTube. The survey covered 5,511 US adults between January 30 and June 18, 2026, with an overall margin of error of plus or minus 1.8 percentage points. [Pew's social media fact sheet](https://www.pewresearch.org/internet/fact-sheet/social-media/) gives the full platform breakdown.

Reach is not the same as fit. Half of adults is a large audience, but a local business still needs the people nearby who can visit, book or call. The platform figures show whether Instagram is worth a test at all. The ad itself should be judged by local enquiries, bookings and calls, because those are the outcomes a nearby customer produces.

## How Should You Structure a Small Reels Test?

Meta's guidance on A/B testing sets the rules for a fair test. It recommends writing a hypothesis first, using the same budget for both versions, and changing one variable at a time. Variables can include ad images, ad text, audience or placement. Meta advises against switching ads or ad sets on and off by hand, because that can overlap audiences and produce unreliable results. The [Meta A/B testing help page](https://www.facebook.com/business/help/1738164643098669) explains the setup.

| Step | What to do | Why |
| --- | --- | --- |
| 1. Write one hypothesis | Example: a Reel with a booking offer beats a brand video on cost per enquiry | Meta recommends a hypothesis before testing |
| 2. Pick one variable | Change either the creative or the audience, not both | Keeps the result readable |
| 3. Set equal budgets | Give each version the same daily spend | Meta says this ensures a fair comparison |
| 4. Run as an A/B test | Use the built-in test tool, not manual on and off switching | Avoids overlapping audiences |
| 5. Judge on cost per result | Compare cost per enquiry, booking or call | Clicks alone can hide poor leads |

At these inputs the test returns less than it cost in the first month. That is normal for a first test and a reason to measure, not a verdict on Reels. Keep the test running only if cost per customer falls below what a customer is worth over the next three months, and if one version beats the other on the same budget. A booking link or unique code helps match each customer back to the ad that brought them in.

Compare the result with other paid options before scaling. ## How Do You Plan Content and Budget Together?

A Reels test works better when the video is ready before the ad budget starts. Plan a short batch of videos, schedule them so the posting calendar does not stall, and then promote the one expected to perform best. A [scheduling comparison for Instagram tools](/blog/later-vs-planoly-instagram-scheduling-local-business) can help choose a tool for that workflow.

Budget size matters as much as creative. The [Facebook ads budget guide](/blog/facebook-ads-budget-local-business-how-much-to-spend) covers how to size a first test across Meta placements, which is useful when Reels is one of several placements under consideration.

Lead generation may suit some businesses better than direct ads. If the goal is calls and booked jobs, compare the Reels test with [Google Local Service Ads](/blog/google-local-service-ads-worth-it-local-business), which are built around local service leads. Put each channel's cost per customer side by side on the same worksheet so the comparison uses the same definition of a customer.

## FAQ

### Is Instagram worth testing for a local business?

Pew Research Center found that 51% of US adults use Instagram in 2026, so it reaches a large audience. Whether it reaches nearby customers depends on the category and location, so test it with a capped budget.

### Can I trust the cost figures for Reels ads?

Not from the sources reviewed here. They do not include Reels-only costs. The search and display benchmarks in the WordStream and Google materials are either dated or from different placements, so use them only as rough context.

### How should I compare two Reels ads?

Use Meta's A/B test tool, give both versions the same budget, and change only one variable. Judge the result on cost per enquiry, booking or call, not on likes or clicks alone.

### How long should the test run?

The sources do not give a duration. Run it long enough to collect a meaningful number of enquiries on each version, and check the result inside Ads Manager before making changes.

### What should I do if cost per customer is too high?

Change the offer or the audience once, then retest. If cost per customer stays above what a customer is worth over three months, stop the Reels test and move the budget to a channel that performed better.

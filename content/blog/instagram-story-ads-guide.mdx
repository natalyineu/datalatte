To run an Instagram Story ad for a local business, create a campaign in Meta Ads Manager, keep the Stories placement, upload a vertical video or image, and add a call-to-action button with a destination you control. The swipe-up link is no longer the way to send people somewhere. Instagram replaced it with a link sticker for organic Stories, and paid Story ads work through a button you set when you build the ad. This guide covers the setup steps, how to choose a button, and a worked budget example that uses labelled assumptions.

## Is There Still a Swipe-Up Link on Instagram Stories?

No, not in the form many local businesses remember. Growwer explains that Swipe Up let users open an external link added to a Story, and that Instagram later replaced it with a link sticker. On the story creation screen, the link option sits in a drop-down menu, and once selected the link appears in the new sticker format inside the Story. Growwer's guide also notes that Swipe Up was only available in Stories, not in feed posts.

Confirm the options in your own Ads Manager before you build the ad.

The table below separates what the sources support from what needs checking in your account.

| Feature | Swipe Up (older, per Growwer) | Link sticker (organic, per Growwer) | Paid Story ad (not verified here) |
|---|---|---|---|
| Where it appears | Story, added in the editor | Story, added from the drop-down menu | Set in Ads Manager when you build the ad |
| How it is added | Chain icon, paste the full URL | Select "link" and enter the URL | Choose a button and destination |
| Tracking | Not provided by Instagram; needs an outside app | Not described in the source | Check Ads Manager results |

## How Do You Set Up an Instagram Story Ad?

The steps below follow the general Ads Manager flow. Menu names change over time, so compare each step with what you see on screen.

1. Pick an objective that matches the result you want, such as website traffic, leads or awareness.
2. Set the audience. Start with a location around your business and add age or interest filters only if you have a clear reason.
3. Choose placements. Keep Instagram Stories switched on, then check the preview to see how the ad looks.
4. Upload a vertical creative with short text that says what the viewer gets.
5. Add a call-to-action button and a destination, such as your website, booking page or phone number.
6. Set a daily budget and a start and end date, then publish and review results after several days.

If a business also runs organic Stories, schedule them separately from paid ads. The [comparison of Later and Planoly for Instagram scheduling](/blog/later-vs-planoly-instagram-scheduling-local-business) covers tools for planning organic posts, which keeps those tasks apart from the paid campaign.

## Which Call to Action Should a Local Business Pick?

Choose the button that matches the next step you want the viewer to take. A salon that takes bookings online should send people to a booking page. A cafe that wants visits can point the button to directions or a menu. A trades business that wants calls can send people to a phone number.

Do not change the button and the destination at the same time. If both change, it is impossible to tell which one caused a difference in results.

## What Creative Should a Story Ad Use?

Use vertical video or a vertical image, and check the preview before you publish. Keep the main words and logo away from the top and bottom edges, where the app's own interface can cover them. Preview on a phone as well as on a desktop, since the crop a viewer sees is the one that matters.

Organic Stories last 24 hours according to Growwer, which is a reason to make each Story easy to understand quickly. A 2024 advice column by Kelsey Weekman, a culture reporter, argues that replies work best when they give the original poster something to answer. That is an opinion about organic replies, not a paid-ad result, but it supports writing creative that invites a response.

Test one creative at a time. Run the same offer, button and budget with two different visuals, then compare cost per result in Ads Manager rather than likes.

## What Does a Story Ad Cost? A Worked Example

The sources checked for this article do not give a verified cost per click or conversion rate for Story ads. The example below therefore uses assumptions only. Replace each assumption with your own numbers after the first test. Keeping the table in a spreadsheet makes that replacement quick.

| Input or result | Value | Label |
|---|---|---|
| Daily budget | $10 for 14 days | Assumption |
| Total spend | $140 | Calculated from budget |
| Cost per click | $1.50 | Assumption |
| Clicks | about 93 | Spend divided by cost per click |
| Conversion rate, click to lead | 5% | Assumption |
| Leads | about 4.7 | Clicks multiplied by conversion rate |
| Cost per lead | about $30 | Spend divided by leads |
| Close rate, lead to paying client | 50% | Assumption |
| New clients | about 2.3 | Leads multiplied by close rate |
| Cost per new client | about $60 | Spend divided by new clients |
| Value of one first visit | $90 | Assumption |
| Revenue from new clients | about $210 | New clients multiplied by first-visit value |

At these assumed inputs, the campaign returns about $210 on $140 of spend, a return of 1.5 times. A small change in close rate or cost per click would move that result a lot. Judge the ad after a real test, and use the cost per new client as the main figure.

## How Should You Test a Story Ad Before Scaling It?

Start with a short test, not a long campaign. Keep the budget small enough that a poor result costs little, and run it long enough to collect a useful number of clicks.

1. Write one hypothesis, such as "a booking button will bring more new client bookings than a directions button."
2. Run two versions that differ in only one element.
3. Let both run for the same period and budget, usually at least a week.
4. Compare cost per result, not impressions or likes.
5. Keep the winner, then test a new variation against it.

Record the start date, budget and the exact change in a simple sheet so the result can be read later. Avoid pausing a version after a handful of clicks, because a small sample can point in either direction. ## FAQ

### Do I need a certain number of followers to run Story ads?

Story ads are bought in Meta Ads Manager, so confirm your Instagram account is connected correctly before you build the campaign.

### How long should a Story ad be?

Keep the offer and button simple and check the preview, since that shows what the account accepts.

### Where does the link go now that swipe-up is gone?

For organic Stories, Growwer describes a link sticker. For paid Story ads, set a destination with the call-to-action button when you build the ad.

### Can I see how many people tapped a link in an organic Story?

Growwer says Instagram does not report swipe-up opens directly, and tracking needs an outside tool. Check the current reporting in Ads Manager for paid ads.

## How Much Does Claude Code Cost?

Claude Code has no separate price tag. It comes with a Claude subscription, and the subscription price is what you pay. Anthropic's pricing page lists these plans:

| Plan | Price | Claude Code | What the page says is included |
|---|---|---|---|
| Free | $0 | Not included | Chat on web, desktop and mobile, web search, file creation, memory, Artifacts. Usage is "limited" |
| Pro | $20 a month, or $17 a month on annual billing ($200 upfront) | Included | Projects, Research, Opus, Claude in Chrome, Microsoft 365 |
| Max | $100 a month | Included | 5x Pro usage, $100 a month in API credits, priority access |
| Ultra | $200 a month | Included | 10x Pro weekly usage, no 5-hour limit for verified accounts, $200 a month in API credits |
| Team | Standard seat $20 a month annual, $25 monthly. Premium seat $100 annual, $125 monthly | Included | Claude Code and Cowork, central billing, SSO |
| Enterprise | $20 per seat a month billed annually, 20-seat minimum, plus usage at API rates | Included per the comparison table | Team features plus audit logs and custom data retention |

One detail matters for budgeting. Anthropic's help article says the monthly API credits that come with Max and Ultra cannot be used in Claude Code. They are a separate benefit.

## What Is Claude Code and How Does It Work?

Anthropic describes Claude Code as "an agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools." In plain terms, it is an assistant that works inside a folder of files. You describe a change in ordinary language and it plans the work, edits files and runs commands.

It runs on several surfaces: the terminal, VS Code and JetBrains extensions, a desktop app and the web at claude.ai/code. The desktop app needs a paid subscription. On a Mac, the terminal install is one line pasted into the Terminal app, and Anthropic's docs include a guide for people who have never opened a terminal.

Claude Code can also connect to outside tools through MCP, an open standard. If that term is new, read [what MCP is and how it works](/blog/what-is-mcp-model-context-protocol-explained).

## What Are the Usage Limits?

Anthropic's help center says Pro and Max have a five-hour session limit and a weekly limit. Ultra has a weekly limit, and verified Ultra accounts have no five-hour limit. Max and Ultra also have a separate weekly limit for Fable models. Terminal and IDE use count toward the same limits as Claude on the web and apps.

The pricing page adds that "how fast you reach a limit depends on the model you use, how long your chats are, and how large your files are." It gives no fixed message count, so any figure you see elsewhere is an estimate, not a vendor promise.

When a limit is reached, the help article lists the options: upgrade, enable usage credits, switch to a Console account with API credits, or wait for the reset.

## What Happens if an API Key Is Set?

If an `ANTHROPIC_API_KEY` environment variable is present, Anthropic says Claude Code uses that key instead of the subscription, which means API charges instead of plan allowance. A non-developer who copied a setup guide may have this variable without knowing. Run `/status` to see which account is active.

The API route is priced per million tokens. The pricing page lists Sonnet 5.5 at $2 input and $10 output, Opus 5.5 at $4 and $20, and Haiku 5.5 at $0.10 and $0.50. It gives no per-task price, so a monthly bill cannot be predicted from these numbers alone.

## What Can a Small Business Use It For?

These are possibilities, not results. Anthropic's overview says Claude Code can build features, fix bugs, edit multiple files and script repeated work. For a local business that could include:

- Editing the text, hours and prices on a landing page, then previewing the change before it goes live.
- Writing a small script that turns an exported sales or booking spreadsheet into a weekly summary.
- Cleaning a customer list: fixing duplicate rows, inconsistent phone formats or missing postcodes.
- Checking a website for broken links or missing page titles.

## What Are the Risks and Limits?

- **Review is the user's job.** Anthropic's security page says "You're responsible for reviewing proposed code and commands for safety before approval."
- **Permissions.** In Manual mode Claude Code starts with read-only permissions and asks before editing files or running commands. The same page says Auto mode, a classifier that reviews actions instead of you, is the starting mode for interactive terminal and VS Code sessions.
- **Data use.** Consumer plans give a choice about training on your data. Anthropic's data page says it will train new models on data from Free, Pro, Max and Ultra accounts when that setting is on, including Claude Code use. Team, Enterprise and API use falls under commercial terms.
- **Sensitive files.** Anything in the working folder can be sent to the model as context. Keep customer lists with personal data out of the folder unless the privacy settings suit that data.
- **Feedback.** Running `/feedback` sends a copy of the conversation, including code, to Anthropic.
- **Limits.** The five-hour and weekly windows can interrupt a long job.

Anthropic also states that "no system is completely immune to all attacks."

## FAQ

### Is Claude Code free?

No. Anthropic's pricing page marks Claude Code as not included on the Free plan. It is included from Pro at $20 a month. The Claude Code overview says most surfaces require a Claude subscription or an Anthropic Console account.

### How much does Claude Code cost per month?

The subscription route is $20 a month on Pro billed monthly, $100 on Max and $200 on Ultra. Team standard seats are $20 a seat a month on annual billing. The API route is billed per token, with no fixed monthly amount.

### Do I need to know how to code to use Claude Code?

The documentation does not set a coding requirement, and it includes a guide for opening a terminal for the first time. It does put the responsibility for reviewing changes on the user, so basic familiarity with websites and files helps.

### Is Claude Code included in Claude Pro?

Yes. Anthropic's help center says Pro, Max and Ultra subscriptions include Claude Code in the terminal and in supported IDEs, and use counts toward the same limits as Claude on the web and apps.

### Does Claude Code use my data for training?

For Free, Pro, Max and Ultra accounts, Anthropic says it trains new models on data when the improvement setting is on, including Claude Code use. Commercial accounts (Team, Enterprise, API) are covered by a policy of not training on Claude Code code or prompts unless the customer opts in.

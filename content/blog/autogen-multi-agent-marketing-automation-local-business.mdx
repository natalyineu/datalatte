Microsoft's AutoGen repository now says the project is archived and no longer actively maintained, and tells new users to start with Microsoft Agent Framework. So a local business starting a multi-agent marketing workflow in 2026 should not begin with AutoGen. For simple jobs such as replying to reviews or compiling a weekly report, a single agent with a clear prompt is usually enough, and cheaper.

This page covers what AutoGen is, what changed, when several agents are worth the extra cost, and a token-cost example. It contains no tested benchmark, because none is published for these tasks.

## What Is AutoGen and What Is Its Status?

AutoGen is an open-source framework for building AI agents. Its documentation lists four parts: AgentChat for conversational single and multi-agent apps, Core for event-driven multi-agent systems, Extensions for connections to outside services, and Studio, a web interface for prototyping.

The repository README now says the project is archived and in maintenance mode, limited to fixes and docs. It describes Microsoft Agent Framework as the enterprise-ready successor. That framework supports Python and C#/.NET, and a migration guide for AutoGen users is linked from its page.

## What Are Multi-Agent Workflows For?

In a multi-agent setup, one agent drafts, another checks, and a coordinator decides when to stop. For a local business that could mean a writer agent drafting a reply to a Google review and a critic agent checking tone and length before you see it. A second pattern splits a weekly report between a data agent, a reviews agent and a social agent.

That structure helps when tasks have separate steps, tools or checks. It adds cost and complexity when one clear prompt would do the job. Start with one agent and add a second only after you see a repeatable error that a checker could catch.

## How Much More Does a Second Agent Cost?

Every extra agent turn is another model call. The example uses Claude Haiku 5.5's list prices of $0.10 per million input tokens and $0.50 per million output tokens (prompts up to 100K tokens).

The inputs are **assumptions**.

| Input | Value |
| --- | --- |
| Review replies a month | 200 |
| Input per call | 1,500 tokens |
| Output per call | 400 tokens |
| Single agent | 1 call per reply |
| Writer, critic, revision | 3 calls per reply |

| Setup | Tokens | Cost |
| --- | --- | --- |
| Single agent | 300,000 in, 80,000 out | 0.3 x $0.10 + 0.08 x $0.50 = about $0.07 |
| Three-call loop | 900,000 in, 240,000 out | 0.9 x $0.10 + 0.24 x $0.50 = about $0.21 |

The loop costs three times as much but is still cents per month at this volume. In practice later calls carry more context, so the real figure is higher. The bigger cost is your time reviewing output. Our guide to [AI agents for Google review management](/blog/ai-agent-for-google-reviews-management) covers what to approve yourself.

## How Do You Install It Today?

The AutoGen README gives the install commands for AgentChat: `pip install -U "autogen-agentchat" "autogen-ext[openai]"`. Microsoft Agent Framework installs for Python with `pip install agent-framework` and for .NET with `dotnet add package Microsoft.Agents.AI`. Both are MIT-licensed.

This page includes no runnable code, because the older `pyautogen` examples found in many tutorials use an earlier version of the API than the current `autogen-agentchat` package. Follow the official docs for the version you install, and test with fake review text before connecting real accounts.

## What Should You Use Instead?

For a first automation, a single scheduled script that drafts replies for your approval is simpler than any agent framework. Our [Google review auto-reply script](/blog/ai-agent-google-reviews-auto-reply-script) shows that approach. If you later need agents that call tools, hand off tasks or run for long periods, evaluate Microsoft Agent Framework or another framework.

Before you commit to any tool, check three things: whether it is maintained, what data it sends to the model provider, and who approves each message before it is published. For definitions, see [AI agent vs chatbot](/blog/ai-agent-vs-chatbot-whats-the-difference-local-business) and [how AI agents work for local businesses](/blog/ai-agents-for-local-business-what-they-are-and-how-they-work). To watch agents in production, read about [AgentOps](/blog/agentops-monitor-debug-ai-agents-local-business).

## FAQ

### Is Microsoft AutoGen still maintained?
The README says the project is archived and no longer actively maintained by Microsoft, and it points new users to Microsoft Agent Framework.

### Do I need several agents to reply to Google reviews?
No. One agent with a good prompt and your approval is enough for most local businesses. A critic agent adds cost and only helps if it catches errors you actually see.

### Is Microsoft Agent Framework free?
The code is MIT-licensed. You still pay the model provider for tokens.

### Can I use Claude with these frameworks?
Check the framework's current docs for supported model clients. This page did not test any integration.

Ollama is a free, open-source tool that runs AI language models on your own computer. Its GitHub repository shows an MIT licence, and its FAQ says that when you run models locally, "we don't see your prompts or data". For a small business, that means you can draft review replies or captions without sending customer text to a cloud AI service.

The catch is hardware and quality. Local models are smaller than the largest cloud models, they need a capable computer, and the software is free but not effortless. This guide covers install, the local API and sensible uses. Facts come from Ollama's own README, docs and model pages, opened on 6 November 2026.

## What Does "Free" Actually Cover?

The software is free under the MIT licence, according to the README. Models are separate downloads with their own licences, and the library pages I checked for Llama 3.2 and Gemma 4 did not state a licence. Read each model's licence before using it commercially.

Your real costs are the computer, its electricity and your time. Ollama's FAQ also mentions cloud-hosted models. These send prompts and responses to ollama.com, so they are not local. If privacy is your reason for using Ollama, stay with models that run on your machine.

## What Computer Do You Need?

Ollama's README does not list RAM requirements, and its model pages list download sizes, not memory needs. For example, the library lists llama3.2 at 1.3 GB (1B) and 2.0 GB (3B), and gemma4 variants from about 4.6 GB to 20 GB depending on size. Treat the download size as a floor, pick a small model first and test it on your machine.

On GPUs, Ollama's docs say it supports NVIDIA cards with compute capability 5.0 or higher and driver version 550 or newer, AMD Radeon cards through the ROCm v7 driver, and Apple GPUs through Metal. If no supported GPU is found, models can run on the CPU, slower.

Ollama stores models on disk (for example `~/.ollama/models` on macOS), so leave free space for each model you pull.

## How Do You Install It?

The README gives these commands:

- **macOS:** `curl -fsSL https://ollama.com/install.sh | sh`, or download the Ollama.dmg installer.
- **Windows:** `irm https://ollama.com/install.ps1 | iex` in PowerShell, or download OllamaSetup.exe.
- **Linux:** `curl -fsSL https://ollama.com/install.sh | sh`.

Piping a script from the internet into a shell runs whatever it contains. If you are not comfortable with that, use the downloadable installer from ollama.com/download instead.

Then run a model. The README's example is `ollama run gemma4`. A smaller choice for a first test is `ollama run llama3.2`, which the library lists at 2.0 GB. The first run downloads the model, then opens a chat prompt.

## How Do You Use It From Your Own Tools?

Ollama exposes a local API at `http://localhost:11434`. Its docs say it binds to 127.0.0.1 by default, which means only your own computer can reach it. Do not set `OLLAMA_HOST` to `0.0.0.0` on a shared network unless you understand the exposure and protect it.

The generate endpoint takes a `model` and a `prompt`. Streaming is on by default, so add `"stream": false` for one JSON reply:

```bash
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Draft a polite two-sentence reply to a 3-star cafe review that says the wait was long. Do not promise refunds.",
  "stream": false
}'
```

The reply text is in the `response` field. Models stay loaded for five minutes by default (`keep_alive`), so the second request is faster than the first.

## Which Small Business Jobs Suit a Local Model?

Good fits are drafting tasks where a person reads the result before it goes out:

- First drafts of replies to Google reviews. Our [guide to automating review replies](/blog/ai-agent-google-reviews-auto-reply-script) explains what to check first.
- Social caption ideas from a list of services you supply.
- Rewriting your own FAQ text into shorter answers.
- Summaries of notes or emails you paste in.

Poor fits are anything needing current facts, exact prices, legal or medical advice, or automatic sending with no review. Small local models can state wrong facts with confidence. Give the model the facts in the prompt, and check the output.

## Does Local Mean Private?

Mostly, for the model itself. The FAQ says Ollama does not see your prompts when run locally. But your files, backups, any web interface you add, and cloud models are separate. If you handle customer health or payment data, ask a qualified adviser about the rules that apply to you before putting that data into any AI tool.

## FAQ

### Is Ollama really free?

The software is MIT-licensed. Models have their own licences, and you pay for hardware and power. Cloud-hosted models in Ollama are not local.

### Does Ollama send my data to the internet?

Ollama's FAQ says it does not see your prompts or data when you run models locally. Cloud-hosted models send prompts and responses to ollama.com.

### How much RAM do I need?

Ollama's README gives no figure. Model pages list download sizes (2.0 GB for llama3.2 3B). Start with a small model and test on your machine.

### Can customers use it through my website?

Not directly. The API listens on your own computer by default. Putting it on the internet needs authentication and security work, so a managed service may be safer.

### Why does it forget long documents?

The default context length is 4,096 tokens. Raise it with `OLLAMA_CONTEXT_LENGTH` or `num_ctx`, which uses more memory.

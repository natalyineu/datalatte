## Is Grok Build Still in Beta?

xAI's launch post (25 May 2026) calls it an early beta. The 19 August post does not call it beta now and says the new features "ship to everyone today". The two xAI posts also disagree on timing: the August post says Grok Build launched "in July" as an early beta limited to SuperGrok Heavy, while the launch post is dated 25 May and lists SuperGrok and X Premium Plus. Press coverage of the beta also differs from these posts, so this guide follows xAI's own pages and notes the conflict rather than picking a date.

## What Is Grok Build and How Does It Work?

xAI describes it as "a new coding agent that runs right from your terminal," built for professional software engineering and complex coding work. Listed features:

- Plan mode, where you approve, comment on or rewrite a plan before execution.
- Support for existing setups: AGENTS.md, plugins, hooks, skills and MCP servers.
- Parallel subagents, which can run in their own git worktrees.
- Headless mode with `-p` for scripts.
- A `/goal` command (introduced 22 June 2026) for long-running autonomous tasks.
- A plugin marketplace (announced 11 June 2026), using commands such as `grok plugin install`.

If MCP is unfamiliar, [this explainer](/blog/what-is-mcp-model-context-protocol-explained) covers it.

## How Do You Set Up Grok Build?

xAI's posts give a single install command for the terminal: `curl -fsSL https://x.ai/cli/install.sh | bash`. Then you sign in with your account. The pages do not name supported operating systems. The August post adds building on the web, iOS and Android, so a terminal is not the only route.

For a non-technical owner, the terminal is the hurdle. If that is a barrier, a visual editor such as [Cursor](/blog/cursor-ai-build-local-business-website-no-code) may be easier.

## What Are the Risks and Limits?

- **Beta wording.** xAI called it an early beta at launch and has not repeated that label in the August post.
- **Unconfirmed terms.** Plan prices, usage limits and data-training terms could not be opened on x.ai for this guide. Read xAI's terms before sending customer data.
- **Autonomy.** `/goal` is described as long-running autonomous execution. That raises the importance of reviewing changes.
- **Review.** Plan mode lets you approve a plan before execution; the owner remains responsible for checking results.

## FAQ

### Is Grok Build free?

Not confirmed. The xAI pricing page returned an error. The API docs say Grok 4.7 Fast is not included in Grok Build's free tier, which implies a free tier exists, but its limits are not stated in the pages opened.

### How much does Grok Build cost?

Subscription prices could not be confirmed from xAI. The API model grok-build-0.1 is $1.00 per million input tokens and $2.00 per million output tokens for prompts under 200k tokens.

### Is Grok Build still in beta?

xAI's 25 May 2026 post calls it an early beta. Its 19 August 2026 post says Grok Build is now available on every plan, on the web and on mobile, and does not use the beta label.

### How do I install Grok Build?

xAI's posts give this terminal command: `curl -fsSL https://x.ai/cli/install.sh | bash`, followed by signing in with your account. The pages do not list supported operating systems.

OpenAI Codex is included with ChatGPT plans: Free at $0, Go at $8 a month, Plus at $20 a month and Pro from $100 a month. Business is $20 per user a month on annual billing. Codex can also run on an API key at usage-based prices, but without the cloud features. You do not strictly need a ChatGPT subscription, though most people start with one.

Prices and features checked on 7 November 2026.

This guide is for owners and marketers of local businesses who want to know what Codex is, what each plan gives and whether it is worth paying for. All numbers come from OpenAI's own pages, listed in Sources.

## How Much Does Codex Cost?

OpenAI's pricing page lists these plans:

| Plan | Price | What the page says about Codex |
|---|---|---|
| Free | $0 a month | Quick coding tasks. Includes GPT-6 Luna at Standard speed in the desktop app, "subject to rollout" |
| Go | $8 a month | Lightweight coding tasks, same GPT-6 Luna access as Free |
| Plus | $20 a month | Codex on the web, CLI, IDE extension and iOS, with GPT-6.1 Sol and GPT-6 Luna, plus automatic code review and Slack |
| Pro | From $100 a month | Plans at $100, $200 or $500 a month. Ultrafast mode is available on the $500 plan |
| Business | $20 per user a month billed annually (2+ users), $25 monthly | Team plan |
| Enterprise and Edu | Contact sales | Priority processing, security controls, Compliance API logs |
| API key | Usage-based | Codex in the CLI, SDK or IDE extension. No cloud features. Billed at API pricing |

Model names change often. The page itself notes that GPT-5.5 retires from Codex with ChatGPT sign-in on 14 October 2026, so check the current list when you sign up.

Other limits stated on the page: Pro plans currently have no five-hour limit, though weekly limits may apply. Fast mode uses 2.5x included usage. Image generation uses limits about 3 to 5 times faster on average and is not available on Free.

## What Are Credits?

When the included limit runs out, Plus and Pro users can buy extra credits. Business, Edu and Enterprise use flexible pricing. Rates are listed per million tokens, as input, cached input and output credits. For example, GPT-6 Luna is 2.5, 0.25 and 12.5 credits, and GPT-6.1 Sol is 50, 2.5 and 250.

The page adds that a typical Sol task "may use 2-15 credits", and that fast mode uses 2x the standard credit rate on purchased credits. It does not state a dollar value per credit in the text opened, so a dollar cost per task is not confirmed here.

## What Is Codex and How Does It Work?

OpenAI's documentation lists Codex surfaces: the ChatGPT desktop app, the ChatGPT mobile app, ChatGPT on the web, the Codex CLI, the Codex IDE extension and Codex Cloud. You describe a task, and Codex reads the project files, edits them and runs commands.

Sign-in is with a ChatGPT account, or with an API key for the CLI, SDK and IDE extension. The pricing page says API-key use has no cloud features and is billed at standard API rates. API prices are separate from subscription usage, so they cannot be used to estimate how many tasks a plan includes.

## Does Codex Need ChatGPT?

Not strictly. The pricing page lists "API Key" as a way to use Codex in the CLI, SDK or IDE extension, available on individual and Enterprise/Edu plans. The trade-off is stated: no cloud features, and billing by usage. For a non-technical owner, a ChatGPT plan is the simpler path because there is one monthly price.

## What Are the Risks and Limits?

- **Sandbox and approvals.** OpenAI's security page says Codex runs under an OS-enforced sandbox, typically limited to the current workspace, and an approval policy controls when it stops to ask. Network access is off by default.
- **Bypass mode.** The `--yolo` flag runs with no sandbox and no approvals. The page marks it as elevated risk and not recommended.
- **Prompt injection.** The page advises caution with network access and web search, because prompt injection can make the agent follow untrusted instructions.
- **Review.** The page advises working on a feature branch and reviewing diffs "like any other pull request".
- **Transcripts.** Codex saves session transcripts under `CODEX_HOME`.
- **Estimates.** Usage figures are estimates and can change.

This guide did not open OpenAI's data-training terms for each plan, so the data-sharing rules per plan are not stated here. Read them before uploading customer data.

## FAQ

### Is OpenAI Codex free?

There is a Free plan at $0 a month for quick coding tasks. OpenAI's page says it includes GPT-6 Luna at Standard speed in the desktop app, subject to rollout. Limits for Free are not stated numerically.

### Does Codex need ChatGPT?

Not always. Codex can be used with an API key in the CLI, SDK or IDE extension, billed at API rates and without cloud features. Most plans, from Free to Pro, are ChatGPT plans.

### How much is Codex per month?

Go is $8, Plus is $20, and Pro starts at $100 (with $200 and $500 options). Business is $20 per user a month on annual billing, or $25 billed monthly.

### What are Codex usage limits?

On Plus and standard Business, OpenAI estimates 5 to 45 messages per five hours for GPT-6 Astra up to 350 to 3,000 for GPT-6 Luna. Pro plans currently have no five-hour limit, though weekly limits may apply.

### Is Codex worth it for a small business?

That depends on the tasks. The Free plan costs nothing to test. A paid plan makes sense only if the owner has recurring file-based jobs, such as page edits or spreadsheet scripts, and someone to review the output.

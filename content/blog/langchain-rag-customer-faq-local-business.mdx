RAG, short for retrieval-augmented generation, lets a chatbot answer from your own documents instead of guessing. You split your menu, price list and policies into chunks, store them as embeddings, find the chunks closest to each question, and pass only those to a language model. For a small business the embedding step costs fractions of a cent: OpenAI lists text-embedding-3-small at $0.02 per 1M tokens. The model that writes the answers is the larger cost.

This guide shows the steps with LangChain, a Python library, and flags what the official tutorial does and does not cover. It needs basic Python. If you prefer no code, see the link to the no-code guide below.

## What Does a RAG FAQ Bot Actually Do?

It answers a customer question in two steps. First it searches your documents for the passages most similar to the question. Then it gives those passages and the question to a chat model with an instruction to answer only from them. If the passage is not there, the bot should say it does not know and offer a phone number.

This is different from a plain chatbot, which answers from what the model learned in training and may invent your opening hours. RAG does not remove errors, but it ties answers to text you control. ## What Do You Need Before You Start?

LangChain's RAG tutorial lists two prerequisites: an API key for a chat model, and an API key for an embeddings provider such as OpenAI for indexing. Its install line is `pip install deepagents "langchain[openai]" langchain-text-splitters requests numpy`, because the tutorial builds a more advanced agent. A simple FAQ bot needs only the LangChain, OpenAI and text-splitter packages.

Prepare your content first. Collect hours, prices, services, parking, cancellation policy and answers to the ten questions your staff hear most. Put each in a plain text file. Remove anything personal, such as customer names or booking records. The quality of the answers depends far more on this text than on the code.

## How Do You Build It Step by Step?

The calls below come from LangChain's tutorial: the OpenAI embeddings class, the in-memory vector store, the recursive text splitter with chunk size 1000 and overlap 200, and the vector store's similarity search with k set to 4. The final answer step is a standard chat model call that the tutorial excerpt does not show. This assembled script was **not run by DataLatte**, so test it before using it.

```python
from langchain_openai import OpenAIEmbeddings
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_core.documents import Document
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain.chat_models import init_chat_model

# 1. Your own text, one entry per topic
faq_texts = [
    ("hours", "We are open Monday to Saturday, 8:00 to 17:00. Closed Sunday."),
    ("cancellation", "Cancel at least 24 hours before your booking to avoid a fee."),
]
docs = [Document(page_content=t, metadata=dict(source=k)) for k, t in faq_texts]

# 2. Split, embed and store
splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200)
chunks = splitter.split_documents(docs)
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
store = InMemoryVectorStore(embeddings)
store.add_documents(documents=chunks)

# 3. Retrieve and answer
llm = init_chat_model(model="anthropic:claude-sonnet-5")

def answer(question: str) -> str:
    hits = store.similarity_search(question, k=4)
    context = "\n\n".join(h.page_content for h in hits)
    prompt = (
        "Answer using only the context. If the answer is not there, say you "
        "do not know and ask the customer to call.\n\n"
        "Context:\n" + context + "\n\nQuestion: " + question
    )
    return llm.invoke(prompt).content
```

The in-memory store forgets everything when the program stops, so rebuild it at start-up or switch to a persistent store as the tutorial's provider tabs describe. ## What Does It Cost to Run?

Embedding your documents is nearly free. The numbers below are **assumptions**: 40 short documents totalling about 60,000 tokens. At $0.02 per 1M tokens, indexing costs about $0.0012. With text-embedding-3-large at $0.13, it is about $0.0078. Each customer question is also embedded, which adds a tiny amount.

The chat model dominates the bill, and its price depends on the model you pick. No chat model price is quoted here because the pricing page for it was not checked. Look up the current rate, then multiply by your expected questions: for example, 500 questions a month, each sending about four chunks plus the question.

Run a trial on real past questions before launch. Ask 30 of them and count wrong answers. A bot that is right 27 times out of 30 still needs a human fallback.

## What Rules Apply to a Customer-Facing Bot?

Tell customers they are talking to a machine. Article 50 of the EU AI Act requires systems that interact directly with people to be designed so people are informed they are dealing with an AI, unless that is obvious. The page checked states the article applies from 2 August 2026, so confirm the current status with a legal adviser.

Data protection still applies. Under GDPR Article 28, a vendor processing personal data for you needs a contract. Do not feed the bot customer records, and do not store chat logs longer than you need. Our [GDPR guide for local business websites](/blog/local-business-website-gdpr-compliance) lists the basics.

## FAQ

### What is RAG in simple terms?
Retrieval-augmented generation. The system looks up relevant passages from your documents and gives them to a language model, so answers come from your text.

### How much does RAG cost for a small business?
Embedding a small document set costs a fraction of a cent at OpenAI's listed $0.02 per 1M tokens for text-embedding-3-small. Chat model usage is the main cost and varies by model.

### Do I need to code to build a FAQ bot?
This guide uses Python. Tools such as n8n and Zapier offer agent builders that need little or no code.

### Can the bot make things up?
Yes. RAG reduces the risk but does not remove it. Instruct the model to answer only from context, test on real questions and give customers a phone number.

### Do I have to tell customers it is AI?
The EU AI Act, Article 50, requires informing people unless it is obvious. Check the application date and local advice.

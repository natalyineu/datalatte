## What Is an ACU?

Devin's usage documentation says: "Agent Compute Units (ACUs)" are how Enterprise customers draw down the volume in their order form, and a federal billing page describes ACUs as representing "how much actual work the agent is doing". The usage page adds that consumption depends on the number and complexity of actions such as planning, gathering context, running code and browser actions. Virtual machine time counts but is "typically a small fraction".

What does not use ACUs, per the same page: waiting for your reply, waiting for a test suite, and cloning repositories. Devin sleeps after 5 minutes of inactivity by default. Windows sessions use about 9% more than Linux.

For self-serve customers the page says plan quota is used first and then prepaid on-demand credits. It points to Settings, then Usage and limits in the app for balances. A price per ACU is not on any page opened, so a monthly bill cannot be calculated from the public pages.

## What Is Devin and How Does It Work?

Devin's documentation calls it "an autonomous AI software engineer that can write, run and test code". It takes tasks such as tickets, bug fixes and new features. Each session includes a shell, an editor and a browser, and you can follow the work in a chat-style interface and step in.

You can use it from the web app, from a terminal tool called Devin CLI, or by tagging it in a Slack or Teams thread. From the CLI a `/handoff` command sends longer tasks to Devin in the cloud. It is aimed at software teams with a code repository, so a business without a developer will find it less direct than a chat-to-page tool like [Lovable](/blog/lovable-pricing-and-credits-2026) or [Replit Agent](/blog/replit-agent-pricing-and-limits-2026).

## Is Devin Desktop the Same as Windsurf?

Devin's Desktop FAQ says: "Devin Desktop is the new name for Windsurf", the same editor with the same features under the Devin brand. It states "Pricing is unchanged" and that "Devin Cloud remains a separate SKU". Devin Local, the agent that runs on your machine, "uses the exact same pricing model", so existing prompt-based credits continue.

The documentation describes Devin Desktop as "the Agent Development Environment for local and cloud agents": run Devin on your machine, delegate to the cloud or connect a third-party agent. In short, Devin the cloud agent works in a remote session and reports back, while Devin Desktop is an app on your computer. The pricing page puts both under one set of plans. For the editor side, with prices and quotas, read the [Windsurf (Devin Desktop) guide](/blog/windsurf-editor-pricing-and-setup-2026).

## What Are the Rules and Risks?

- **Who owns the output.** Cognition's Platform Terms, last updated 30 June 2026, say "Cognition assigns to you all right, title, and interest in Output", and that you own your Customer Data.
- **Training on your data.** The same terms say Cognition "may use Customer Data for model training purposes and to improve and enhance the Services". On a paid tier you may opt out, and on Teams only an administrator can opt out. After an opt-out, data is not used for training language models. Other Devin pages worded this differently, so check the setting in your account.
- **Competing products.** The terms bar uses of the service such as training competing AI models without written approval.
- **Security reports.** Cognition's trust centre lists a SOC 2 Type 2 report, available on request after an NDA. It does not state data-training rules.
- **No quota numbers.** Usage cannot be forecast from public pages.
- **Review.** Code written by an agent needs a person to read it before it reaches a live site or customer data.

Devin's browser and shell can reach whatever you connect, so connect only the accounts a task needs.

## FAQ

### How much does Devin AI cost?

Free is $0, Pro is $20 a month, Max is $200 a month and Teams is $80 a month plus $40 per full dev seat. Enterprise is custom. These are on devin.ai/pricing.

### What is an ACU in Devin?

An Agent Compute Unit measures how much work the agent does. Planning, actions, browser use and code execution all count. The pricing page names no ACU price or plan allowance.

### Is Devin free?

Yes, there is a Free plan with a "light quota to code with agents" and limited model availability. Pro adds increased quotas, Devin Cloud access and frontier models.

### Is Windsurf now Devin?

Windsurf is now called Devin Desktop, per Devin's FAQ. Pricing is unchanged, and Devin Cloud remains a separate product.

### Is Devin worth it for a small business?

Only if someone can review code. It targets software tasks, so a business without a developer may do better with a page builder. Try Free before paying.

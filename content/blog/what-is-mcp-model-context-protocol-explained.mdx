MCP, the Model Context Protocol, is an open standard that lets AI applications connect to outside systems such as files, databases, calendars and business tools. The official MCP site compares it to a USB-C port for AI: one standard connection instead of a custom cable for each tool. Anthropic announced it on November 25, 2024.

For a small business owner, MCP matters because it is how an AI assistant can read your calendar or spreadsheet, and sometimes act on it, without a developer building a one-off integration. This guide explains the parts in plain terms, what it can do, what to check before connecting anything and where the sources stop. Examples are labelled as assumptions.

## What Does MCP Actually Do?

The MCP documentation defines it as an open-source standard for connecting AI applications to external systems: data sources such as local files and databases, tools such as search engines and calculators, and workflows such as specialised prompts. Its own examples include an agent that reads Google Calendar and Notion to act as a more personal assistant.

Before a standard like this, each AI product needed its own connector for each tool. With MCP, a tool maker builds one server, and any AI app that supports the protocol can use it. The MCP site lists Claude, ChatGPT, Visual Studio Code and Cursor among supporting clients. Support in your particular app and plan can change, so check your app's settings.

## How Is It Built: Host, Client and Server?

Three roles appear in the architecture docs. The host is the AI application, such as Claude Desktop or Claude Code. The host creates one client for each server it connects to. The server is a program that provides context to the client.

A server can run on your own computer, called local and using the stdio transport, or on a vendor's platform, called remote and using Streamable HTTP. The docs give a filesystem server as a local example and Sentry's official server as a remote one. A server can offer three kinds of things: tools, which are actions the AI can run, resources, which are data it can read, and prompts, which are reusable templates.

| Piece | What it is | Example |
| --- | --- | --- |
| Host | The AI app you use | Claude Desktop |
| Client | Connection inside the host, one per server | Calendar connection |
| Server | Program that exposes data or actions | Calendar or file server |
| Tool | An action the AI can call | Create an event |
| Resource | Data the AI can read | A spreadsheet's contents |

## What Could a Small Business Use It For?

The sources describe capabilities, not business results, so treat these as possibilities. Anthropic's launch post named pre-built servers for Google Drive, Slack, GitHub, Git, Postgres and Puppeteer. How much it can do depends on the permissions you grant. ## What Are the Risks?

An MCP connection gives software access to your data, so treat it like giving a staff member a login. The MCP project publishes security best practices that cover several attacks. For local servers it warns that a malicious startup command could run arbitrary code with your privileges, and says clients must show the exact command and ask for approval first. It also recommends running servers with limited access to files and the network.

On permissions, the same document recommends least privilege: ask for a minimal scope first and add more only when needed. For an owner this means three habits. Install servers only from sources you trust. Connect read-only access first. Review any action the AI proposes before approving writes such as sending messages or editing calendars. The sources do not give rates for how often attacks happen, so none are quoted.

## FAQ

### Is MCP only for Claude?

No. The MCP site calls it an open protocol and lists Claude, ChatGPT, Visual Studio Code and Cursor among supporting clients. Check that your own app supports it.

### Do I need to code to use MCP?

Not to use existing servers through an app that offers them. Building your own server does need development skills.

### Is MCP the same as an API?

No. An API is a particular tool's interface. MCP is a common standard that an AI app uses to talk to many tools, which often call those APIs behind the scenes.

### Is it safe?

It depends on the server and the permissions. The MCP security guidance warns about untrusted local servers and recommends least-privilege access. Use trusted sources and start read-only.

### What does it cost?

The protocol is open source. Costs come from the AI app plan and any vendor server. The sources here do not give prices.

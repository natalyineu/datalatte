You can build a simple client CRM for a salon, groomer or studio in Notion and let Claude read and update it through Notion's hosted MCP server. Notion says MCP works on every plan and signs in with OAuth, so a non-developer can connect it in a few minutes. Claude then searches your client database, adds visit notes and lists who is due for a follow-up. You still check every message before it is sent.

## What Is Notion MCP?

MCP is a standard way for an AI app to use outside tools. Notion MCP is a remote server hosted by Notion that works through the Notion API. After you authorise a connection with OAuth, the client can read and update content you can access. Only workspace members can connect it, so guests cannot.

The tool list includes search, fetch, create pages, update pages, create databases and query data sources. For background, read our [explainer on the Model Context Protocol](/blog/what-is-mcp-model-context-protocol-explained) and the [MCP server roundup for local businesses](/blog/best-mcp-servers-local-business-setup-guide).

## How Do You Connect It?

For Claude Code, Notion documents one command: `claude mcp add --transport http notion https://mcp.notion.com/mcp`, then `/mcp` to complete the OAuth flow. The endpoint is the Streamable HTTP address `https://mcp.notion.com/mcp`.

Notion's page covers Claude Code only. For Claude's desktop or web apps, add Notion as a connector in that app's settings and check Anthropic's current instructions. For unattended jobs, Notion says a workspace owner on a Business or Enterprise plan can create an MCP token in the Developer portal and send it as a bearer token. The old open-source `@notionhq/notion-mcp-server` still exists, but its README recommends the hosted one.

## What Should the CRM Database Contain?

Keep it small. Every field you add is a field someone must fill in. A starting set for a service business:

| Property | Type | Why it is there |
| --- | --- | --- |
| Client name | Title | Search key |
| Phone or email | Phone / Email | To send the follow-up |
| Last visit | Date | Finds lapsed clients |
| Service | Select | What they usually book |
| Notes | Text | Preferences, sensitivities, pet details |
| Next follow-up | Date | Drives reminders |
| Consent to message | Checkbox | Only contact people who agreed |

The consent field matters. Store only what you need, tell clients how you use their details, and check the privacy rules where you operate. Notion also warns that integrations only see content that has been shared with them, so keep client data in a clearly labelled workspace.

## What Should You Automate First?

Start with read-only tasks, then add writing once you trust the results.

1. **After-visit note:** you dictate or type a line, Claude finds the client record and adds it to Notes.
2. **Follow-up list:** ask Claude each Monday for clients whose last visit was more than a set number of weeks ago and who gave consent, with a draft message for each.
3. **Weekly summary:** new clients, returning clients and clients not seen for a while, from the fields you recorded.

A prompt such as this is enough to start:

```text
Search the Client CRM for clients with Consent checked and Last visit
more than 8 weeks ago. For each, draft a two-sentence text that
mentions their usual service. Do not send anything.
```

## FAQ

### Is Notion MCP free?

Notion says MCP works on every plan, but some features depend on the plan. MCP tokens for headless use need Business or Enterprise.

### Do I need to code?

Not for the hosted connection and manual prompts. Unattended automation needs a Business or Enterprise plan with an MCP token and some scripting.

### Is the old npx notion-mcp-server still the right choice?

Its README says it is no longer actively maintained and recommends the hosted Notion MCP server.

### Can Claude send messages to my clients?

Notion MCP does not send texts. Claude drafts, and you send from your own phone or messaging tool after review.

### Is it safe to put client details in Notion?

Only store what you need, only contact clients who agreed, and follow your local privacy law. Limit workspace access to people who need it.

## What Is Contributor Mode?

Meta's subscriptions page says Muse Code subscriptions default to Contributor mode. The page says that in this mode "you get more usage from your plan in exchange for letting Meta use your content to train future Meta models." Your content means the prompts, code, files and context you send and the responses you get back.

You can turn it off at any time, "at which point your future content is not used to train Meta models." The page also says the mode does not appear for pay-as-you-go billing, accounts with Zero Data Retention, or organizations whose managed configuration sets it off. The subscriptions page does not describe a price discount for Contributor mode; the benefit it names is more usage.

## What Are the Per-Token Prices?

For people who use the API route instead of a subscription, the product page lists two versions of each model. The Contributor versions are labelled "Used to improve our products." The Standard versions are labelled "Not used to improve our products." Both have a 1M-token context window.

| Muse Spark 1.3 and 1.2 | Input per million tokens | Output per million tokens |
|---|---|---|
| Contributor versions | $0.10 | $0.20 |
| Standard versions | $1.25 | $4.25 |

On Meta's figures, the Standard input rate is 12.5 times the Contributor rate ($1.25 divided by $0.10), and the Standard output rate is 21.25 times ($4.25 divided by $0.20). That is arithmetic on Meta's numbers. Press coverage of the contributor tier exists, but it is secondary and is not used for any fact here.

## What Is Muse Code and How Does It Work?

Meta's docs describe Muse Code as its coding agent for the terminal and CI, built for Muse Spark. Run it in a project and it plans, edits files and runs commands. The product page adds that it is multi-agent by default, with workers in parallel and reviewers in the background, and that its actions are auditable.

Install is one line. On macOS or Linux: `curl -fsSL https://dev.meta.ai/install.sh | sh`. On Windows, a PowerShell command is given. The docs say to run `muse` inside a project folder, choose whether to trust the workspace and sign in through a browser or an API key. The default model is `muse-spark-1.2`.

Platforms differ slightly between pages. The product page says "Available for MacOS and Windows" and the docs say macOS, Linux and Windows. Neither page labels the product as beta, and neither gives a launch date.

## What Are the Risks and Limits?

- **Data sharing.** Contributor mode is the default. Do not send customer lists, staff details or anything confidential while it is on. Turn it off in settings first if that matters.
- **Approvals and sandbox.** Meta's permissions page says two safeguards apply: an approval policy and an OS-level sandbox. Writes are limited to the workspace and a temp directory, and network access defaults to per-destination approval.
- **Removing guardrails.** The `--yolo` option disables both layers and the docs reserve it for disposable, already-isolated environments.
- **Usage caps.** The Everyday plan allows 10 to 50 prompts per 5 hours.
- **Review.** Output still needs a person to check it before it goes live.
- **Unconfirmed.** Meta's pages opened do not state a free plan, a refund policy or a beta label.

## FAQ

### What is Meta Muse Code?

It is Meta's coding agent for the terminal and CI, built for Muse Spark models. It plans a task, edits files and runs commands, with approvals and an OS sandbox on from the first run.

### How much does Meta Muse Code cost?

The product page lists Everyday Usage at $5 a month, High Usage at $15, Power Usage at $50 and Maximum Usage at $200. The subscriptions page lists usage but no prices.

### What is Muse Code Contributor mode?

It is the default for subscriptions. Meta says you get more usage in exchange for letting Meta use your content to train future models. You can turn it off at any time, after which future content is not used for training.

### Is Meta Muse Code free?

The pages opened do not list a free plan. The cheapest plan listed is Everyday Usage at $5 a month.

### Is Muse Code safe for business data?

Meta's docs describe approvals and a sandbox, but Contributor mode is on by default and allows content to be used for training. Turn it off, or use pay-as-you-go billing where the mode does not appear, before working with business or customer data.

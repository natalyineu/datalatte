An n8n workflow can watch a Gmail inbox for new inquiries, sort each one into a category with an AI model, save a drafted reply for you to approve and log the lead to a Google Sheet. The n8n documentation lists a Gmail Trigger, a Text Classifier, an AI Agent, a Gmail node that can create drafts and a Google Sheets node that can append rows, so every step has a built-in node.

This guide walks through that design, what n8n costs on its pricing page and how to keep a person in the loop. It does not include an importable JSON file: node names and parameters change between n8n versions, and a file that cannot be tested against your version is more risk than help.

## What Does a Lead Follow-Up Workflow Look Like?

The workflow has six steps. Each maps to a node the n8n docs describe.

1. **Gmail Trigger.** Fires on "Message Received". The docs list filters for label, search text, read status (unread only is the default) and sender, plus a poll interval you choose. Use a label or a dedicated inquiries address so only real leads start the workflow.
2. **Text Classifier.** Sorts the email into categories you define, each with a name and a description. Examples: new booking enquiry, price question, complaint, spam. The node has an option to send items that match no category to an extra "Other" output instead of discarding them.
3. **Branch.** Complaints, refunds and anything under "Other" go to a person. Only clear enquiries continue.
4. **Draft the reply.** An AI Agent or a basic LLM step writes a short reply from your prompt and a few facts you supply, such as hours and prices.
5. **Gmail, Create Draft.** The Gmail node supports creating a draft as well as sending and replying. A draft means nothing leaves your account until you press send.
6. **Google Sheets, Append Row.** Log date, sender, category and whether a draft was created. This log is your evidence that the workflow works.

The Gmail Trigger has a Simplify option, on by default, that returns only IDs, labels and headers such as From and Subject. To give the model the email text, turn Simplify off so the full message comes through.

## Should You Use the AI Agent Node or a Classifier?

The n8n docs describe the AI Agent node this way: you connect a chat model and one or more tools, and the agent decides which tools to call. At least one tool must be connected, and all AI Agent nodes now work as a Tools Agent.

For a lead inbox, the more predictable design is a classifier first, then a fixed draft step. An agent that picks its own tools is flexible but harder to test. Use the agent when leads vary a lot, such as when it must look up your calendar or price list, and keep its tools to the minimum: create a draft, read the sheet.

## How Do You Self-Host n8n?

Self-hosting avoids the monthly plan but adds server work. The n8n Docker page says you need technical self-hosting skills (server and container setup, resource management, security) and warns that mistakes can cause data loss, security issues or downtime.

The page is marked outdated and points to a Docker Compose guide. Its basic command is:

```bash
docker volume create n8n_data

docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -e GENERIC_TIMEZONE="<YOUR_TIMEZONE>" \
  -e TZ="<YOUR_TIMEZONE>" \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n
```

The `n8n_data` volume holds encryption keys and logs, so keep it. For production use, follow the current Docker Compose install guide in the n8n docs, and put the server behind HTTPS. If that sounds like too much, n8n Cloud removes the work.

## How Do You Keep the Agent Safe?

- Start in draft mode only. Review every draft for a week before trusting the classifier.
- Tell the model in the prompt never to promise prices, availability or guarantees you have not approved.
- Send complaints, refunds, health or legal topics to a person.
- Store API keys in n8n credentials, not in the workflow text or prompts.
- Test with your own emails first, including spam and angry messages.
- Check what your email provider and local rules require before sending automated replies to customers.

## Is It Worth Building? A Worked Example

Every input below is an **assumption**. Replace it with your own numbers.

| | Assumption |
| --- | --- |
| Inquiries per month | 60 |
| Minutes to read, sort and draft one reply by hand | 5 |
| Minutes to review one draft | 1 |
| Value of your time | $30 an hour |
| n8n Cloud Starter | $20 a month |
| AI model cost per inquiry | under $0.01 |

By hand: 60 x 5 minutes = 5 hours, worth $150. With drafts: 60 x 1 minute = 1 hour, worth $30. Time saved is 4 hours, worth $120. Subtract the $20 plan and well under $1 of model use, and the net gain is about $100 a month before setup time.

On Anthropic's [pricing page](https://platform.claude.com/docs/en/about-claude/pricing), Claude Haiku 5.5 is listed at $0.10 per million input tokens and $0.50 per million output tokens for prompts up to 100,000 tokens. At an assumed 1,200 input and 300 output tokens per inquiry, one inquiry costs about $0.0003.

The caveat is volume. At 10 inquiries a month the same maths saves about $20 of time, which only matches the plan price, so a saved-reply template may beat any automation. The workflow also does nothing about the real bottleneck if leads go cold because nobody follows up after the first reply. ## What Should You Do First?

1. Count the inquiries your inbox received in the last 30 days and how long each reply took.
2. Write three to five category descriptions for the classifier, including a category for messages a person must handle.
3. Start the n8n Cloud free trial and build only the first three steps: trigger, classifier, sheet log. Run it on your own test emails.
4. Add the draft step, and review every draft by hand for a week.
5. Compare the log with your inbox after two weeks and fix mislabelled categories before you widen the scope.

## FAQ

### Do I need programming knowledge to use n8n?

Not for the visual workflow, but some basic comfort helps. You connect nodes in an editor. A Code node uses JavaScript, and you will read error messages when a credential or field is wrong. If server setup worries you, start with n8n Cloud.

### Can n8n send the replies automatically?

Yes. The Gmail node can send or reply to a message as well as create a draft. Start with drafts and move to sending only for the safest category, such as a confirmation of receipt.

### How many executions will I use?

That depends on how n8n counts executions for your trigger and how often it polls. The pricing page bills by workflow executions, so test for a week and read your usage before choosing a plan.

### Is n8n better than Make.com or Zapier for this?

Neither is universally better. n8n offers a self-hosted free edition and execution-based plans, which can suit higher volumes. For a small inbox, the cheapest plan on any platform may be enough. The [n8n beginner guide](/blog/n8n-for-local-business-automation-beginners-guide) lists other first automations.

### Can the same pattern handle appointment reminders?

Yes, with a Schedule Trigger and a message node, but check consent and local texting rules first. The appointment reminder script shows the logic in code.

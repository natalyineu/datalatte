To build a Facebook Custom Audience from past customers, export a clean list with emails or phone numbers, upload it in Ads Manager, and target ads at the people Meta can match. Meta requires identifiers to be hashed with SHA256 before matching; Ads Manager does this for a file upload, while API uploads must hash first. Meta publishes no match rate, so treat any figure you see elsewhere as an estimate.

## What Is a Customer List Custom Audience?

It is a set of people you already know, matched to Meta accounts by identifiers such as email and phone. You can then show ads only to them, or exclude them from ads meant for new customers. For a local business, the common uses are win-back offers, new-service announcements and keeping existing clients out of first-visit promotions.

The list is your data, and Meta's documentation says you are responsible for what you upload, including data from your CRM. Accounts must accept the Custom Audience Terms before an audience can be created. Only upload people who gave you their details for marketing or whose use your local law allows.

## How Do You Prepare the List?

Use one row per person. Meta's schema accepts email, phone, first and last name, first initial, gender, date of birth, city, state, zip, country and mobile advertiser ID. Normalise each field the way Meta describes before hashing:

| Field | Rule before hashing |
| --- | --- |
| Email | Trim spaces, lowercase |
| Phone | Remove symbols, letters and leading zeros; add a country code |
| First / last name | Lowercase, no punctuation |
| City | Lowercase letters a-z only, no spaces |
| State | Lowercase two-letter US code |
| Zip | US: first 5 digits; UK: area/district/sector format |
| Country | Lowercase two-letter ISO code |

Meta says to include several keys together (for example first name, last name and email) to improve matching. It states no minimum audience size on that page.

## Do You Have to Hash the Data Yourself?

In the API, yes: hash with SHA256 and output lowercase hex, since other methods are not supported. External IDs and mobile advertiser IDs are the exceptions. Each request can take up to 10,000 users, so larger files are split, and changes usually take up to 24 hours to apply.

If you upload a file through Ads Manager, normalising correctly is your job. A secondary vendor guide says Ads Manager hashes the file on Meta's side; confirm this on screen. Marketing tools that connect through the API will hash for you.

## Which Audiences Should a Local Business Build?

Match each list to one goal.

| Audience | Goal | Example offer (illustrative) |
| --- | --- | --- |
| Customers in the last 90 days | Repeat visit | New service or add-on |
| Customers not seen for 6+ months | Win-back | A reason to return |
| Top spenders | Retain | Early access to a slot |
| Everyone | Exclusion | Keep out of new-customer ads |

The 90-day and 6-month cut-offs are examples, not Meta rules. Pick windows that match how often your customers rebook. ## What Will It Cost? A Worked Example

All inputs are **assumptions**, except the cost per lead, which is LocaliQ's all-industry average for Facebook lead campaigns (updated 23 September 2026).

| Input | Value |
| --- | --- |
| Past customers on the list | 800 |
| Share matched by Meta (assumption) | 50% |
| Audience size | about 400 |
| Bookings wanted from win-back | 15 |
| Share of leads that book (assumption) | 40% |
| Leads needed | about 38 |
| Cost per lead (LocaliQ average) | $27.39 |
| Budget | about $1,030 |

A $1,030 spend for 15 bookings is about $69 each, which only works if a returning client is worth more than that. Past customers know you, so their real cost per lead may be lower, but LocaliQ publishes no figure for existing-customer lists. Start with a smaller test and compare cost per booking with your margin. See the [Facebook ads budget guide](/blog/facebook-ads-budget-local-business-how-much-to-spend) for the formula.

Meta also flags audiences that suggest health conditions or financial status, so avoid building lists around them. Audiences unused in active ad sets for over two years are flagged for deletion.

## FAQ

### Is a Custom Audience legal?

It depends on how you collected the data and where you operate. Meta makes you responsible for the data and requires you to accept its terms. Ask a local adviser if unsure.

### What match rate should I expect?

Meta's developer page publishes none. Vendor blogs quote ranges, but they are not Meta figures.

### How long until the audience is usable?

Meta says changes usually take up to 24 hours to apply.

### Can I use my email list from Mailchimp?

You can export it and upload it, provided your sign-up terms covered advertising use.

### How big should the list be?

The developer page states no minimum. Small audiences may show little or no match detail.

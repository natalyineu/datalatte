The Gemini API costs a local business almost nothing for small jobs. Google's pricing page lists a free tier for every Flash model, and the cheapest paid model, Gemini 2.5 Flash-Lite, costs $0.10 per 1M input tokens and $0.40 per 1M output tokens. The catch is data: on the free tier Google may use what you send to improve its products, so keep customer details out of it.

This guide covers prices checked on 31 October 2026, what the free tier means in practice, a first API call, and a cost example. Figures that are examples are labelled as assumptions.

## How Much Does the Gemini Flash API Cost?

Prices below are standard-tier text prices per 1M tokens, read from Google's pricing page, which showed an update date of 30 October 2026. Output prices include thinking tokens.

| Model | Free tier | Input | Output |
| --- | --- | --- | --- |
| gemini-2.5-flash-lite | Yes | $0.10 | $0.40 |
| gemini-3.1-flash-lite | Yes | $0.25 | $1.50 |
| gemini-3.5-flash-lite | Yes | $0.30 | $2.50 |
| gemini-2.5-flash | Yes | $0.30 | $2.50 |
| gemini-3-flash-preview | Yes | $0.50 | $3.00 |
| gemini-3.6-flash | Yes | $0.75 until Dec 31, 2026, then $1.50 | $3.75 until Dec 31, 2026, then $7.50 |
| gemini-3.8-flash | Yes | $0.75 until Dec 31, 2026, then $1.50 | $3.75 until Dec 31, 2026, then $7.50 |

Audio input is priced higher on several models. Model names and prices change often, so check the page before you commit to one.

## What Does the Free Tier Actually Give You?

Every Flash model in the table is listed as "free of charge" on the pricing page. Google's rate limit page does not publish free-tier numbers. It says limits are measured in requests per minute, input tokens per minute and requests per day, that they apply per project and not per API key, and that daily quotas reset at midnight Pacific time. Your own limits are shown in Google AI Studio.

For a small business this is usually enough to test an idea. It is a poor base for something customers depend on, because limits can be low and preview models are more restricted.

## Is It Safe to Send Customer Data to the Free Tier?

No. Google's Gemini API terms (effective March 23, 2026, last updated April 28, 2026) say that on unpaid services Google uses submitted content and generated responses to improve its products, and that human reviewers may read it. The terms tell users not to submit sensitive, confidential or personal information to unpaid services.

On paid services, Google says it does not use prompts or responses to improve its products. It logs them for a limited period only to detect and prevent violations. For users in the EEA, Switzerland and the UK, the paid-service terms apply to all services, including free ones.

In practice: use the free tier for drafts built from public information, such as review text you already published. Switch billing on before you process booking details, phone numbers or health information.

## How Do You Make Your First Call?

Google's quickstart installs the Python library with this command:

```
pip install -U google-genai
```

The library reads your key from the `GEMINI_API_KEY` environment variable. Create the key in Google AI Studio, set the variable, and copy the current example from the quickstart. Google changes its sample code and default model name between releases, so copy from the live page instead of an old tutorial.

Two habits keep costs and risk down. Put a fixed instruction in front of every request, such as the tone of your replies and what the model must not promise. Have a person approve anything that goes to a customer.

## The Math: What Does a Month of Review Replies Cost?

All inputs are **assumptions** for illustration. A café gets 40 new reviews a month. Each request sends about 600 input tokens (instructions plus the review) and returns about 150 output tokens. Thinking tokens, if a model uses them, count as output and would raise the figure.

| | Value |
| --- | --- |
| Input tokens per month (assumption) | 40 x 600 = 24,000 |
| Output tokens per month (assumption) | 40 x 150 = 6,000 |
| Cost on gemini-2.5-flash-lite | 0.024 x $0.10 + 0.006 x $0.40 = about $0.005 |
| Cost on gemini-2.5-flash | 0.024 x $0.30 + 0.006 x $2.50 = about $0.022 |

Even at 100 times the volume the bill stays under about $2.50 on the pricier model. The real cost is your time to review each draft, not the API.

## What Are the Limits?

Prices for the newest Flash models rise on January 1, 2027, so a budget built on today's 3.x rates will double for those models. Older and Lite models are cheaper but may be retired. Models can write confident wrong answers about your hours or prices. Never let one answer from memory: put your real details in the prompt.

## FAQ

### Is the Gemini API free for small businesses?

Google lists a free tier for its Flash models. Limits apply per project and Google may use free-tier content to improve its products, so avoid personal data.

### Which Gemini model is cheapest?

On the pricing page checked on 31 October 2026, gemini-2.5-flash-lite is cheapest at $0.10 input and $0.40 output per 1M tokens.

### Do I need to know how to code?

For a first test, no: Google AI Studio lets you try prompts in the browser. Running it on a schedule needs a script or a tool like Zapier.

### Will prices change?

Yes. Google has already announced that gemini-3.6-flash and gemini-3.8-flash prices rise on January 1, 2027.

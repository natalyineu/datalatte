AgentOps is an observability tool for AI agents. You add `agentops.init()` to your code, and it records each run so you can replay it, see where it failed and watch what it spends. The Basic plan is free up to 5,000 events a month, and Pro starts at $40 a month (AgentOps pricing page, checked 31 Oct 2026).

This guide is for a local business owner or a freelancer who has built an agent for reviews, bookings or FAQs and needs to find out why it sometimes gives a wrong answer. It covers what AgentOps records, what it costs, and when a simpler option is enough. Figures come from the vendor pages listed at the end.

## What Does AgentOps Actually Do?

AgentOps describes itself as a platform for testing, debugging and deploying AI agents and LLM apps. Once the SDK is initialised, it tracks calls to supported LLM providers automatically, including OpenAI, Anthropic, Google Gemini and LiteLLM. Its docs list integrations with CrewAI, AutoGen (AG2), LangChain, Google ADK, Haystack and the OpenAI Agents SDK.

The dashboard has a session list and a session waterfall. The docs say the waterfall shows a time view of your LLM calls, action events, tool calls and errors. The pricing page also lists cost tracking for 400+ LLMs and "time travel debugging", which it describes as rewinding and replaying agent runs.

## How Do You Add It to an Agent?

Install the package, create an API key in your AgentOps account and initialise it before your first model call. The docs show this setup:

```python
import agentops
agentops.init(<INSERT YOUR API KEY HERE>)
```

The docs say to call `init()` after importing your LLM library and before making the call. For manual control of what counts as one run, AgentOps documents a `@trace` decorator. A TypeScript SDK also exists. The SDK changed between versions, so older tutorials that use `agentops.record` or `end_session` may not match the current docs. Follow the current docs page, not a copied snippet.

## What Does AgentOps Cost Compared With Alternatives?

All prices below were read from each vendor's pricing page on 31 Oct 2026. Pro and Team plans add usage-based charges that the pages point to calculators for, so treat the monthly figure as a starting point.

## Do You Need It at All?

Not always. A single model call with a fixed prompt, such as a review reply drafter that you read before posting, can be checked by reading its output. Your model provider's own usage page also shows spend. Add an observability tool when an agent has several steps or tools, runs without you watching, or has already produced an answer you could not reproduce.

AgentOps is also open source: its GitHub page says the app is MIT licensed and can run on your own cloud. If customer messages pass through the agent, check where prompts are stored before sending them to any hosted service. For a plain overview of agents, read [AI agents for local business](/blog/ai-agents-for-local-business-what-they-are-and-how-they-work).

## A Worked Example: Is the Free Tier Enough?

All inputs are **assumptions**. A salon runs a reply agent for Google reviews and an FAQ agent for its website.

| Input (assumption) | Value |
| --- | --- |
| Reviews answered per month | 40 |
| FAQ chats per month | 300 |
| Recorded events per review run | 5 |
| Recorded events per FAQ chat | 8 |

Events would be 40 x 5 = 200 plus 300 x 8 = 2,400, so 2,600 per month. That is under the 5,000 free limit on the Basic plan, with room for roughly twice the chat volume at the same event counts. How many events AgentOps counts per LLM call is defined by the vendor, so check your dashboard after a week and replace these numbers with the real ones.

## How Do You Debug a Wrong Answer?

Use the session list to find the run by time. Open the waterfall to see the order of calls, then read the exact prompt and tool results that fed the bad answer. Most failures turn out to be bad input to the model, such as an out-of-date price in a tool result, not the model itself. Fix the source, then watch the next runs. ## FAQ

### Is AgentOps free?

Yes, within limits. The pricing page lists a Basic plan at $0 a month for up to 5,000 events, with the SDK, LLM cost tracking and replay analytics. Pro starts at $40 a month.

### Which frameworks does AgentOps work with?

The docs list AG2, Agno, AutoGen, CrewAI, Google ADK, Haystack, LangChain, the OpenAI Agents SDK and Smolagents, plus LLM providers such as OpenAI, Anthropic and Google.

### Does AgentOps track cost?

The pricing page says it manages and visualises agent spend and includes LLM cost tracking in the Basic plan. The tracking docs page does not describe what is stored per call, so check your own dashboard.

### Can I self-host it?

The GitHub page says the app is open source under the MIT license and that you can run it on your own cloud. The pricing page lists on-premise or self-hosted deployment under Enterprise, so confirm which route applies to you.

### Is it safe for customer data?

The pages read do not describe data handling. Prompts and replies are recorded, so they may contain customer names. Read the vendor's privacy terms first, and avoid sending health data to any service you have not reviewed.

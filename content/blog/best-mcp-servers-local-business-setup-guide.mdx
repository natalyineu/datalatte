## What Is an MCP Server in Plain Terms?

MCP is an open standard for connecting AI applications to outside systems such as files, databases and tools. The official introduction compares it to a USB-C port for AI. An MCP server is the piece that sits in front of one tool and tells the AI what it can do there. If the idea is new, read [what MCP is](/blog/what-is-mcp-model-context-protocol-explained) first.

There are two kinds. A **remote** server is hosted by the vendor and you sign in with OAuth. A **local** server runs on your computer. Most small businesses should prefer remote servers, because there is no file to edit and no code to run.

## How Do You Connect a Hosted Server to Claude?

Claude calls these custom connectors. They are available on Free, Pro, Max, Team and Enterprise plans, and the Free plan is limited to one. On Pro or Max the path is Customize, Connectors, Add, then a custom connector: name it, paste the server URL, check the sign-in settings and click Add. On Team and Enterprise an Owner adds the connector first and members then connect individually.

Anthropic warns that custom connectors are not verified by Anthropic. Connect only to servers you trust, turn off tools you do not need, and be careful with "Allow always". During Research, Claude can call connector tools without asking, so disable tools that write data.

## What Does Each Hosted Server Do?

**Notion.** Notion hosts its own server. After OAuth, Claude can search, read, create and update pages and databases your account can reach. Restricting which clients members may use needs the Enterprise plan.

**Slack.** The server can search messages, files and channels, read threads, and send or draft messages. It works only through directory-published or internal apps, and a workspace admin has to approve the app. That makes it a poor first choice for a solo owner.

**Supabase.** Setup is a browser sign-in, with no access token needed. Supabase says production projects can hold sensitive data, so scope the server with `project_ref`, turn on `read_only=true`, and keep manual approval of tool calls on. It also says not to give the server to customers. Our [Supabase connector guide](/blog/mcp-supabase-connector-ai-agent-database) covers the database side.

**Google Calendar, Drive and Gmail.** Google documents one remote server per product, at `calendarmcp.googleapis.com`, `drivemcp.googleapis.com` and `gmailmcp.googleapis.com`. They are a Developer Preview, you need to join the program, and you must enable the APIs in a Google Cloud project and create an OAuth client. Treat this as a project for someone technical, not a five-minute install. For booking, see [Claude and Google Calendar](/blog/claude-mcp-google-calendar-booking-automation).

## Should You Use the Local Filesystem Server?

Yes, if you keep documents on one computer. The maintained Filesystem server only reads and writes inside directories you list. Its entry in `claude_desktop_config.json` uses the command `npx`, with the arguments `-y`, `@modelcontextprotocol/server-filesystem` and then one folder path per allowed directory, for example `/Users/username/business-docs`.

The README says Node.js 24 or later is needed for `npx`, and on Windows the command is launched through `cmd /c`. Its `write_file` tool overwrites existing files, so point it at a copy of your documents, not your only copy.

Claude Desktop also offers extensions (Settings, Desktop app, Extensions) that replace manual JSON editing. Anthropic says Claude Desktop includes its own Node.js, so extensions need no separate install.

## What Are the Risks?

Three are worth acting on. First, an archived server gets no security fixes; the repository states that no security guarantees are provided. Second, text inside your data can try to steer the AI. Supabase calls this prompt injection and recommends keeping manual tool approval on. Third, a connector acts with your permissions, so a connector to your Gmail can read what you can read. Start with read-only access, then add write access one tool at a time.

## FAQ

### Are MCP servers free?

The protocol is open source. Hosted servers are offered by the vendors, and their pricing is set by each vendor's own plan. This page did not verify vendor plan prices for Notion, Slack or Supabase, so check those plans yourself.

### Do I need Claude Pro to use MCP?

No for remote connectors: Anthropic lists custom connectors on the Free plan, limited to one. Paid plans remove that limit.

### Do I need to edit a JSON file?

Not for hosted servers: you add them in Claude's Connectors settings. JSON editing applies to local servers such as Filesystem.

### Which old MCP packages should I stop using?

The repository lists AWS KB Retrieval, Brave Search, EverArt, GitHub, GitLab, Google Drive, Google Maps, PostgreSQL, Puppeteer, Redis, Sentry, Slack and SQLite as archived.

### Can an MCP server see everything in my account?

It can reach what your sign-in allows. Limit it with read-only mode, a single project or folder, and by disabling tools you do not need.

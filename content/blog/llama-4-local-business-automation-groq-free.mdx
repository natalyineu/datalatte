## Can You Still Use Llama 4 on Groq?

No. Groq lists both Llama 4 models in its deprecation history. The announcement for Maverick went out on February 20, 2026, and for Scout on June 17, 2026. Groq recommends `openai/gpt-oss-120b` for Maverick and either `openai/gpt-oss-120b` or `qwen/qwen3.6-27b` for Scout.

If an older script still names a `meta-llama/llama-4-*` model, it will fail. Change the model name and test it again before relying on it.

## Which Groq Models Can You Use Instead?

Groq's models page currently lists these production models: `llama-3.1-8b-instant`, `llama-3.3-70b-versatile`, `openai/gpt-oss-120b`, `openai/gpt-oss-20b` and two Whisper speech models. Preview models change more often and can be withdrawn, so keep them out of anything customers depend on.

| Model | Notes from Groq's pages |
| --- | --- |
| llama-3.3-70b-versatile | Meta Llama, 131,072-token context, 32,768 max output. Price not on the model page |
| openai/gpt-oss-120b | 131,072-token context, 65,536 max output, $0.15 input and $0.60 output per 1M tokens |
| llama-3.1-8b-instant | Listed as a production model. Details not checked here |

For a drafting job that a person approves, any of the production text models can work. Test two or three on your real examples.

## Is the Groq API Really Free?

Groq has a free plan, but it publishes no single number for it. Its rate-limits page says limits apply per organization, that any of requests per minute, requests per day, tokens per minute or tokens per day can be hit first, and that going over returns HTTP 429. It also says higher limits and Batch or Flex processing need the Developer plan. The table on that page shows Developer plan limits, and the exact limits for your account are on the Limits page in the console.

Third-party guides quote different free-tier numbers that disagree with each other, so this article gives none. Check your console before you plan volume. See our [GPT-4o mini vs Groq cost comparison](/blog/gpt-4o-mini-vs-groq-llama-cost-comparison-2026) for how paid prices compare.

## How Do You Set It Up?

The setup takes four steps.

1. Create a Groq account and an API key in the console.
2. Install the SDK with `pip install groq`.
3. Create a client and call `client.chat.completions.create()` with a model name, as in Groq's quickstart.
4. Store the key in an environment variable, never in the script or in a shared document.

A minimal draft-a-reply script, using a model from the table above:

```python
import os
from groq import Groq

client = Groq(api_key=os.environ["GROQ_API_KEY"])

review = "Great haircut but I waited 25 minutes past my slot."
prompt = (
    "Write a polite 60-word reply from a hair salon owner to this "
    "Google review. Do not promise refunds. Review: " + review
)

completion = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": prompt}],
)
print(completion.choices[0].message.content)
```

Read the draft yourself and post it by hand. Our [AI agent for Google reviews](/blog/ai-agent-for-google-reviews-management) guide covers approval rules and platform limits.

## Which Jobs Suit a Free or Cheap Model?

Short drafting tasks with a human check suit it well: review replies, first drafts of social captions, FAQ answers from your own text, and appointment reminder wording. Anything that sends messages automatically, handles payments or quotes prices needs more care, because a model can state wrong facts with confidence.

Keep customer names, phone numbers and health details out of prompts unless you have checked Groq's data terms for your use. This article did not review those terms.

## FAQ

### Is Llama 4 free on Groq in 2026?

It is not available at all. Both Llama 4 models on Groq are deprecated, and Groq's models page lists none.

### What replaces Llama 4 on Groq?

Groq recommends `openai/gpt-oss-120b` for both models, and `qwen/qwen3.6-27b` as another option for Scout. Llama 3.3 70B is still a production model.

### How many free requests do I get?

Groq does not publish one fixed number on the pages checked. Limits depend on the model and your organization, so read the Limits page in your console.

### Can I run Llama 4 somewhere else?

Yes, through other providers or locally, but this article did not check them. See our [free OpenRouter models guide](/blog/best-free-openrouter-models-business-automation) for that route.

### Is AI safe for replying to customers?

Use it for drafts only. Review each message for facts, tone and promises before posting.

## How should a Baltimore fitness studio set up its Google Business Profile?

Google's guidelines say a business with a physical location, or one that travels to customers, can create a Business Profile. The profile must reflect the business accurately, and the studio should avoid prohibited content. Google recommends that the name, address, service area, hours, and categories match what customers see in the real world, such as on signage and branding.

Google also recommends choosing the fewest categories needed to describe the core business. For a studio, that usually means one primary category, such as a gym or yoga studio, plus only the extra categories that truly describe its services. Adding many loosely related categories makes the profile less clear to both customers and Google.

Each studio should keep one profile per location. Google notes that multiple profiles for one business can cause problems with how information displays on [Google Maps and Search](https://support.google.com/business/answer/3038177). A studio with two Baltimore locations can give each one its own profile, but a single location should never be split into several.

## Which name and description rules matter most for fitness studios?

Google asks businesses to use the name customers know in the real world, as shown on storefronts and stationery. The name field should not include taglines, store codes, hours, phone numbers, URLs, or fully capitalised words. A studio called "Charm City Barre" should not add "Open 6am to 9pm" or "Free Trial" to the name, because the profile can be suspended for it.

The business description has its own limits. It should explain services, products, mission, and history honestly. It should not focus on special promotions, prices, or sales, and it should not contain links of any type. A studio that wants to promote a trial class can do that in a Google post or on its website, where promotional content fits better.

The table below summarises the main fields and what Google's guidelines say about each.

| Profile field | Google guidance | Common mistake for studios |
|---|---|---|
| Business name | Real-world name, as used on signage | Adding hours, taglines, or class types |
| Categories | Fewest needed to describe core business | Stacking many loosely related categories |
| Description | Services, mission, history, no links | Listing prices, sales, or website URLs |
| Address and service area | Accurate and precise | Hiding the real address or listing a vague area |
| Profiles | One per business | Duplicate profiles for each class type |

## How long does it take for local SEO changes to appear?

Google's [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) says every change takes time to be reflected. Some changes may take effect in a few hours, while others could take several months. In general, the guide suggests waiting a few weeks before deciding whether a change had a beneficial effect.

This matters for Baltimore studios because many owners change everything at once and then judge the results after one week. A better approach is to change one group of items at a time, such as photos or the description, and log the date of each change. Google also notes that not every change produces a visible result in search. If results are weak and the business strategy allows it, the studio can adjust and test again.

## Do website signals still matter for the Maps listing?

The SEO Starter Guide explains that search engines work best when they can crawl and understand a site. Pages should be visible to the same resources a user's browser can access, because hidden scripts or styles can stop Google from understanding a page. A class schedule that loads only through a script may be read poorly.

Google's [LocalBusiness structured data documentation](https://developers.google.com/search/docs/appearance/structured-data/local-business) describes how to mark up local business details for search. A studio should compare its website details with its profile so that the name, address, and phone number match exactly. For a contact page that shows the studio's location, the [Google Maps embed guide](/blog/google-maps-embed-local-business-website) explains the steps.

Clear, descriptive URLs also help. The SEO Starter Guide notes that words in a URL can appear as breadcrumbs in search results, so a page named for its content, such as a class schedule, tells users what they will find before they click.

## What steps should a Baltimore studio follow?

1. Confirm that the studio has exactly one profile for each physical location.
2. Match the name, address, and phone number to signage and the website.
3. Choose the fewest categories that describe the core business.
4. Write a description that explains services without prices, sales, or links.
5. Post updates on a steady schedule and track results over several weeks.
6. Check how Google sees your pages using the URL Inspection Tool in Search Console.

## FAQ

### Can a Baltimore fitness studio have more than one Google Business Profile?

Google's guidelines say there should be one profile per business, because multiple profiles can cause problems with how information displays on Google Maps and Search. Each separate physical location can have its own profile.

### Can a studio put its class prices in the business description?

No. Google's guidelines say the description should not focus on special promotions, prices, or offers, and it should not contain links. Prices and offers belong on the website or in posts.

### How long should a studio wait before judging a local SEO change?

Google's SEO Starter Guide suggests waiting a few weeks to assess whether a change had a beneficial effect. Some changes may appear within hours, while others could take several months.

### Does the business name need to match the sign on the door?

Yes. Google asks businesses to use the real-world name, as shown on storefronts, stationery, and branding. Adding hours, taglines, or class types to the name is not allowed.

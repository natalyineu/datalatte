n8n is a workflow automation tool that connects apps such as Gmail, Google Sheets and Google Calendar through a visual editor. A local business can start with n8n Cloud, which the [n8n pricing page](https://n8n.io/pricing/) lists at €20 a month billed annually for 2,500 workflow executions, or self-host the free Community edition. n8n publishes no figure for hours saved, so this guide makes no such promise. The five automations below use nodes documented by n8n, and any example numbers are labelled as assumptions.

## What Does n8n Cost for a Small Business?

The [n8n pricing page](https://n8n.io/pricing/) lists Starter at €20 a month billed annually with 2,500 executions and Pro at €50 with 10,000. Business is listed at €667 with 40,000 executions, on self-hosted only. Enterprise pricing is custom. A monthly billing toggle exists, but the monthly prices did not appear when the page was read, so the annual figures are the ones to budget with.

An execution is a single run of your entire workflow, however many steps it has. A workflow that runs once a day uses about 30 executions a month. The Community edition is available on GitHub with no listed price.

## Is n8n Free to Self-Host?

The software is free to run, but you carry the server, updates and backups. The [n8n hosting docs](https://docs.n8n.io/hosting/) describe Docker Compose for production and a one-line setup script, and say npm installation is deprecated from n8n 3.0. Without a license key, a self-hosted instance runs as the free Community edition.

The [Sustainable Use License](https://github.com/n8n-io/n8n/blob/master/LICENSE.md) allows use for your own internal business purposes or non-commercial use. Sharing it is allowed only free of charge and non-commercially. If you plan to resell n8n as a service, read the license text first.

The table below compares the two routes for a single shop. The server fee is an assumption, not a quoted price.

| Option | Monthly cost | What you maintain |
| --- | --- | --- |
| n8n Cloud Starter | €20 billed annually (listed) | Workflows only |
| Self-hosted Community | Server fee of about €5 (assumption) | Server, updates, backups |

For a business that cannot run a server, the listed Cloud price is usually the simpler budget line.

## Which Automations Are Worth Building First?

Pick tasks that are repetitive, rule-based and low risk. Each of these five uses n8n nodes whose operations are documented:

- Daily booking digest: the Schedule Trigger runs at a fixed time, reads rows from Google Sheets and emails the day's list through Gmail.
- Lead capture: a Webhook node receives a form submission and appends a row in Google Sheets.
- Appointment check: Google Calendar's Get Many events and Availability operations read your calendar. For a broader comparison of booking and scheduling software, see [Jobber vs ServiceTitan for small business](/blog/jobber-vs-servicetitan-small-business-local-business).
- Email draft for enquiries: Gmail can create a draft for you to review before sending.
- Review request list: a sheet of recent customers feeds a reminder for staff to ask for reviews.

Email is the channel most of these workflows touch. Mailchimp's benchmark data puts the all-user average open rate at 35.63% and the Business + Finance average at 31.35%, with an unsubscribe rate of 0.15% for that group. The data was last updated in December 2023, and Mailchimp notes that Apple's Mail Privacy Protection can affect open rates, so treat them as a rough baseline. Each automation works best when a person reviews the output before it goes out. For a wider look at AI models in these workflows, see [Gemini Flash API for local business automation](/blog/gemini-flash-api-local-business-automation).

## What Do the Key Nodes Actually Do?

The Schedule Trigger runs at intervals from seconds to months, or on a cron expression. The workflow must be published for it to run. It uses the workflow or instance timezone: self-hosted defaults to America/New York and Cloud to GMT. Set the timezone before you trust any time-based output.

The Webhook node creates a URL that receives data and supports GET, POST and other methods, with a 16 MB payload limit. It has separate test and production URLs, and the production URL is the one a form should call. Gmail supports sending, replying and creating drafts. Google Sheets supports append, update and get rows.

If you want an AI assistant to read or trigger these tools directly, the setup is covered in [best MCP servers for local business setup](/blog/best-mcp-servers-local-business-setup-guide).

## Will Your Plan Cover Your Workflows?

All inputs below are assumptions. The example salon builds a daily digest, a form capture workflow and a daily review-request check.

| Workflow | Assumed runs per month | Executions |
| --- | --- | --- |
| Daily booking digest | 30 days | 30 |
| Form capture (one run per submission) | 80 submissions | 80 |
| Review-request check, daily | 30 days | 30 |

140 executions is far under Starter's 2,500. The limit matters when a workflow runs per customer message, because each run counts. ## FAQ

### Is n8n free?

A self-hosted Community edition is available on GitHub. n8n Cloud is paid, starting at €20 a month billed annually for 2,500 executions, according to the [pricing page](https://n8n.io/pricing/).

### Do I need to code to use n8n?

The editor is visual. The hosting docs do not state a required skill level, but self-hosting involves Docker or a similar setup, so many small businesses choose Cloud.

### What counts as an execution?

n8n defines an execution as a single run of your entire workflow. Step count and data volume do not change that.

### Can n8n send emails and read my calendar?

Yes. Documented operations include Gmail send, reply and draft, and Google Calendar get, create and availability checks.

### How many hours will n8n save me?

n8n publishes no figure. Time the task yourself: count the minutes it takes now, then compare after a month of running the workflow.

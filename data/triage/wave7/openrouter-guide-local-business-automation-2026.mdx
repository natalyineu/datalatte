OpenRouter is an API gateway. One account and one API key give you access to the models listed on its platform, which its [Discover page](https://openrouter.ai/discover) counts at 627. Requests follow the same pattern whichever model you pick, so switching providers means changing one model string. Kilo's documentation says [OpenRouter charges based on the underlying model's pricing](https://kilo.ai/docs/ai-providers/openrouter), so you pay each model's listed rate. For a local business, the practical uses are review replies, social captions and email drafts. Keep a human approval step on anything customers will read.

## What Does OpenRouter Actually Do for a Local Business?

OpenRouter is a routing layer, not a model. Kilo describes it as a platform that gives access to a wide variety of language models from different providers, all through a single API. For a salon or cafe, the benefit is administrative: one key, one dashboard and one place to check spend.

The catalogue is large and uneven in quality. The Discover page lists third-party scores from the Artificial Analysis intelligence index on a 0 to 100 scale. Claude Fable 5.2 from Anthropic scores 65, Gemini 4 Carbon from Google scores 60, GPT-6 Astra from OpenAI scores 57, and Grok 4.7 from SpaceXAI scores 36. The page also notes that Anthropic edges Google by 5 points on that index.

An index score measures general ability on a benchmark. It does not show how a model will handle a harsh review about your flat white. Test candidate models on your own real prompts before you commit.

## How Do You Make Your First OpenRouter API Call?

Setup takes only a few minutes. Follow these steps:

1. Create an account at [openrouter.ai](https://openrouter.ai).
2. Create an API key in the dashboard and copy it when it is shown.
3. Store the key in an environment variable, not in your code or a shared document.
4. Copy the exact model ID from that model's page on the Discover listing.

OpenRouter's [API reference](https://openrouter.ai/docs/api_reference/overview) documents sampling settings such as `top_k`. That value must fall in the range `[1, Infinity)`, and the page states it is not available for OpenAI models. Leave it out of requests that go to OpenAI models.

```python
import os
import requests

API_KEY = os.environ["OPENROUTER_API_KEY"]
MODEL = "provider/model-id"  # copy the exact ID from the model page

def draft_review_reply(review_text, business_name):
    response = requests.post(
        "https://openrouter.ai/api/v1/chat/completions",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={
            "model": MODEL,
            "messages": [
                {"role": "system", "content": f"You are the owner of {business_name}. Reply warmly to Google reviews in under 80 words. Do not add offers, prices or details that are not in this message."},
                {"role": "user", "content": review_text},
            ],
            "max_tokens": 150,
        },
        timeout=30,
    )
    response.raise_for_status()
    return response.json()["choices"][0]["message"]["content"]

print(draft_review_reply("Best cortado in town!", "The Daily Grind Cafe"))
```

To switch models, change only the `MODEL` line. The rest of the script stays the same.

## Which Model Fits Each Local Business Task?

Match the model to the cost of a mistake. A wrong sentence in a public review reply is more expensive than a clumsy caption you can edit in ten seconds.

| Task | What goes wrong if the text is off | Model to test first |
|---|---|---|
| Replies to negative reviews | Tone problems or a promise you never authorised | Highest-scoring model you can afford on the index, with human review |
| Customer emails | Off-brand voice or wrong dates | Mid-range model, with a human check |
| Social captions from a template | Low stakes and easy to edit | Lower-cost model, generated in batches |
| Long menus or policy documents | Missed details in long text | Long-context model such as [Gemini Flash](/blog/gemini-flash-api-local-business-automation) |

Free models on OpenRouter carry an endpoint ID ending in `:free`. A secondary benchmark from Vibecoder Journal tested all 22 active free models on 19 September 2026, but it covers coding tasks and says its weekly refresh is overdue. Treat those results as a snapshot and check the live list before relying on any free model.

## How Reliable Are AI-Written Replies Before You Publish Them?

Hightouch, citing Stanford accuracy benchmarks that tested 26 top-tier frontier models, reports hallucination rates ranging from 22% to 94% (secondary source). That range covers models in general, not your business, but it is enough reason to keep a person in the loop. The main danger is invented detail: a discount that does not exist, a wait time you never quoted or a staff name the model guessed.

Use this checklist to reduce that risk:

1. Put verified facts into the prompt, including opening hours, current offers and staff names.
2. Instruct the model not to add anything that is not in the prompt.
3. Save each draft to a queue instead of posting it directly.
4. Read every reply to a negative review before it goes live.
5. Record which model wrote each draft so you can compare results later.

## FAQ

### What is OpenRouter?

OpenRouter is an API gateway. It gives you access to the models listed on its platform, which its Discover page counts at 627, through one API. You manage one key and one dashboard instead of separate accounts with each AI provider.

### How is OpenRouter priced?

Kilo's documentation says OpenRouter charges based on the underlying model's pricing. Check the rate on each model's page before you budget, because prices differ by model and can change.

### Can I switch models without rewriting my code?

Yes, for the most part. The request structure stays the same and you change the model string. Remember that some parameters, such as `top_k`, have rules. OpenRouter's API reference says it is not available for OpenAI models, so remove it from those requests.

### Should I send customer data through OpenRouter?

Review OpenRouter's current privacy and logging policies on its website before sending personal information. As a general precaution, leave customer contact details out of prompts. Review replies usually need only the review text and your business name.

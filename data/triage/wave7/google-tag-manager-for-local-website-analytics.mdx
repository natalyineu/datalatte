Google Tag Manager (GTM) is a free Google service that lets you add and change tracking tags on a website without editing its code each time. For a local business, the common job is sending Google Analytics 4 (GA4) the actions that matter, such as phone taps and booking clicks. You install the container once, then manage tags from the GTM interface.

This guide covers what GTM does, what GA4 already records, six setup steps, call-tracking pitfalls, and a worked cost-per-booking example with assumed inputs.

## What Does Google Tag Manager Do for a Local Website?

A GTM container holds your tags, triggers and variables. A tag sends data or runs a function, such as a GA4 event. A trigger decides when the tag fires, for example when a visitor clicks a link. A variable is a reusable value, such as the link address that was clicked.

Google describes connecting data sources such as Google Analytics and Google Tag Manager to Google Ads so that AI can learn from your signals and improve campaign performance ([Google Ads](https://business.google.com/en-all/google-ads/)). Clean event data is the input that makes this work, which is why it is worth setting up correctly from the start.

## What Does GA4 Already Track Without GTM?

Google recommends turning on Enhanced Measurement for websites ([Adwave, secondary](https://adwave.com/resources/setting-up-google-analytics-4-a-small-business-walkthrough)). Check that setting in GA4 before you build custom tags, so you do not count the same action twice. The [GA4 setup guide for local businesses](/blog/google-analytics-4-setup-local-business) walks through the settings to review first.

GA4 has limits for local leads. Google Analytics cannot directly track Local Services Ads performance, because those leads come through Google Business Profile rather than your website ([Ryze, secondary](https://www.get-ryze.ai/blog/google-local-services-ads-reporting-tool)). A phone tap on your site is a separate signal, and GTM is how you capture it.

If an older guide mentions Universal Analytics, note that Google says it was the default property type for websites before October 14, 2020 and is no longer available ([Google Marketing Tools Support](https://business.google.com/us/support/)). A new setup should use a GA4 property.

## How Do You Set Up GTM and Track Local Actions?

Follow these six steps in order. Each one ends with a check you can complete in under an hour on a small site.

1. Create a Tag Manager account and a web container for your domain.
2. Add the two container snippets to every page. Adwave lists installation guides for Shopify, WordPress, Wix, Squarespace, Webflow and hand-coded sites, so follow the one that matches your platform ([Adwave, secondary](https://adwave.com/resources/website-navigation-architecture)).
3. Add a GA4 configuration tag so GA4 receives data through the container. Remove any older GA4 snippet so a page does not send the same data twice.
4. Create click triggers and GA4 event tags for phone taps and booking clicks, as described in the next section.
5. Test in preview mode, then confirm each event in GA4's real-time reports.
6. Publish the container and give the version a clear name so you can roll back later.

## How Do You Track Phone Taps and Booking Clicks?

Create a trigger that fires on link clicks. Add a condition on the click URL: one that begins with tel: for phone numbers, or one that contains your booking tool's domain. Connect that trigger to a GA4 event tag with a plain name such as phone_tap or booking_click.

Track the calls to action that matter. patientMoon defines CTAs as calls to action that lead potential clients to take action on a website ([patientMoon, secondary](https://www.patientmoon.com/marketing-business-strategy/pilates-studios)). For most local sites, that means the phone number in the header, the booking button and the contact form, not every link in the footer.

If you also send calls to Google Ads as conversions, read Google's call tracking guidance first. Google says its tag cannot verify your domain when installed through a tag management system such as Google Tag Manager ([Google Ads Help](https://support.google.com/google-ads/answer/6095883)).

Google's guidance adds three more limits. The phone number entered must match the exact digits on your website. The standard GTM call conversion tag is not compatible with international number formats. Google does not recommend using GTM for this tag if your site uses Dynamic Number Insertion or third-party call tracking.

## How Do You Test GTM Before You Publish?

Open GTM's preview mode and browse your site as a visitor would. Click each phone link and booking button, then confirm the matching tag fires once, not twice. A double fire usually means an old GA4 snippet is still on the page, so return to step 3.

Next, open GA4's real-time reports and check that each event appears with the name you chose. Compare the phone number in the tag with the number shown on the site. Publish only when every event behaves as expected.

## How Do You Compare Tracked Events With Ad Spend?

Google Analytics assigns a sign-up to the last campaign that brought the user to the website ([LivePlan, secondary](https://www.liveplan.com/blog/starting/track-marketing-return-on-investment)). That shortcut can make an ad look more or less useful than it was, so treat any single number with caution.

Adwave advises examining ad exposure, website activity and completed actions separately, using documented data and an appropriate comparison period before attributing outcomes to advertising ([Adwave, secondary](https://adwave.com/resources/google-business-profile-insights-what-your-analytics-actually-mean)). The same source reports that website clicks make up 48% of Google Business Profile actions, more than phone calls (21%) or directions (9%).

## FAQ

### Is Google Tag Manager free?

Yes. Impact BC describes Google Tag Manager as one of the free services from Google ([Impact BC, secondary](https://www.impactbc.com.sg/ultimate-guide-digital-marketing-success/)). Your main cost is the time to set up and test tags.

### Do I need GTM if GA4 is already installed?

Not always. GA4's Enhanced Measurement covers many basic interactions. GTM is useful when you need custom events such as phone taps or booking clicks, or when you want to manage several tags in one place.

### Does GA4 record Local Services Ads leads?

Not directly. Google Analytics cannot track Local Services Ads performance, because those leads come through Google Business Profile ([Ryze, secondary](https://www.get-ryze.ai/blog/google-local-services-ads-reporting-tool)).

### Should every click be a tracked event?

No. Track the actions tied to bookings and calls, plus the calls to action that lead visitors to act. Extra events make reports harder to read.
